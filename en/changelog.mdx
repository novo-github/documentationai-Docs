## New Features

### User Permissions Editor

Administrators can now control exactly which pages and machines each user has access to — directly from the Admin Panel, with no backend configuration required.

- Open any user's record and select **Edit Permissions**.
- Choose which platform pages the user can see and which machines they can access.
- Save the changes. They apply on the user's next session.

### AI Chat History

The AI assistant now has a dedicated full page under **Workspace → Chat History**.

AI Chat History is available for documentation only and does not access live production or machine data.

- All conversations are saved and easy to return to.
- **Star** conversations to pin them at the top, **rename** them for reference, or **delete** ones you no longer need.
- Answers are context-aware based on the page you were on when you opened the chat.

## Quality of Life Improvements

### Orders & Products

The Orders & Products table now surfaces significantly more data in the same view — and you can configure exactly what you see.

**New columns available:**
- **Customer** — colour-coded chip showing which customer the order belongs to.
- **Priority** — colour-coded badge for Critical, High, Medium, or Low orders.
- **Planned & Actual Durations** — planned time versus what actually occurred.
- **Avg. Cycle Time** — average production cycle time per order.
- **Cycle Time Deviation** — difference between actual cycle time and the plan.
- **Setup Time Deviation** — difference between planned and actual preparation time.
- **Interval Count** — number of production intervals logged against the order.

**Your configuration is saved:** Toggle columns on or off using the column visibility button, and your selection is restored on every visit across sessions.

### Assignment Planner

Finding and managing operations in the planner is now significantly faster.

- **Search** the unassigned operations queue by order name, product, or operation.
- **Filter by Order Tags** and **Priority** to narrow down the list quickly.
- **View and edit notes and descriptions** on any operation or assignment directly from the planner.

### Order Upload Planner

The upload process is now more flexible and informative.

- **Upload Order Tags** alongside your order data to pre-tag orders on import.
- **Industry minutes toggle** — switch time field interpretation between standard and industry minutes.
- **Machine-assigned orders only** — import only orders that are already assigned to a machine.
- A **progress bar** shows upload status in real time.
- **Schedule conflict warnings** appear in the preview step before committing, so you can fix issues in the source file first.

### Data Acquisition (PDA)

Several improvements reduce manual effort and prevent errors on the shop floor.

- **Operation sequence number** is now shown on every job chip, so operators always know which step they are logging against.
- **Automatic order status updates** — when an operator starts or stops production, the order status updates automatically.
- **Over-production prompt** — when produced quantity exceeds the planned amount, a prompt asks the operator whether to mark the order as completed.
- **Operation and assignment notes** are accessible directly from the PDA page.

### Saved Column Preferences

Every column visibility configuration you set is automatically saved to your account and restored on every visit. No reconfiguration is needed after refreshing or switching pages.

### AI Chat Sidebar

The floating chat assistant (available from every page) is your quickest way to understand the platform.

- Ask how any feature works and get an answer grounded in the official documentation.
- Use it to understand what actions are available on the page you're currently on.
- Find workflows, settings, and navigation guidance without leaving your current context.

For a complete reference, visit the **Documentation** page — it covers every page, workflow, and available action across the platform.

*For questions about any of these features, contact your platform administrator or reach out to the Watchmen support team.*
