## Releases

<Update label="2026-08-19" description="v1.5.90" tags={["feature", "improvement"]}>
  **UI-Build commit:** `54e018d`

  **Release date:** August 19, 2026

  ### New Features

  #### Review and Correct Uploaded Order Files

  After selecting an order file, you can now preview its file name, row and column count, and a sample of its contents before continuing.

  Select **Expand to edit** to open the full file view. You can correct individual values, paste matching groups of values from Excel, and see how many cells you have changed before saving.

  - Column headings and row counts remain fixed, so the file structure cannot be changed accidentally.
  - Saved corrections are highlighted in the preview, making adjustments easy to review.
  - Closing the editor without saving discards unsaved changes and leaves the original file unchanged.

  #### Understand Time-Setting Effects Before Uploading

  The upload review now explains when a time value or the **Industrial minutes** setting changes preparation or production time, and identifies the affected row. This provides a clearer final check before you confirm an upload.

  #### Identify Operations Using Industrial Minutes

  Operations that use industrial minutes now show an **Industrial minutes** label next to their planned times. Hover over the label for a short explanation of the time convention.

  ### Improvements

  #### Choose How Operations Are Ordered

  Within a work order, you can now sort operations by sequence number. Select the sort button beside **Add operation**, then choose **Ascending** or **Descending** to review the work in the order that best fits your planning or shop-floor workflow.

  #### Delete Incorrect Time Entries

  You can now remove an incorrect recorded time entry from Order Analysis. Open the entry menu, select **Delete**, review the displayed start and end time, and confirm the deletion.

  Deletion is permanent. Once confirmed, Order Analysis and the related timeline immediately reflect the current production record.
</Update>

<Update label="2026-07-30" description="v1.5.85" tags={["feature", "improvement"]}>
  **UI-Build commit:** `d52000872`

  **Release date:** July 30, 2026

  ### [Improved Operator Settings](/en/platform-intro/workflows/operator-management)

  Operator administration now provides clearer and safer controls for managing operator access and credentials.

  ### New Features

  #### Safer Operator Deactivation

  Administrators can deactivate an operator immediately without deleting historical data. Previous shifts, labels, and assignments remain preserved.

  #### Generate New Operator Passwords

  Administrators can generate a new password for eligible operators from **Edit operator**. Active sessions are ended, and the operator must sign in again with the new password.

  Generated credentials are displayed only once and can be copied or downloaded before the window is closed.

  #### Explicit Email Verification

  Verification emails are sent only when an administrator explicitly requests one. They are never sent automatically after creating or editing an operator or regenerating an operator's password.

  Unverified operators can still sign in and use their assigned access.

  ### Administration Improvements

  Only active operators are displayed in Operator Settings. Status indicators, confirmation messages, credential actions, and administration buttons now provide a clearer and more consistent experience.
</Update>

<Update label="2026-07-26" description="v1.5.80" tags={["feature", "improvement"]}>
  **UI-Build commit:** `8b115707b`

  **Release period:** Late June–July 2026

  ### New Features

  #### [Redesigned Orders & Products Dashboard](/en/platform-intro/pages/orders-products)

  Orders & Products now provides a table-focused workspace for monitoring and analyzing production orders.

  - Filter by customer, order, product, machine, date range, assignment status, or live production.
  - Use summary cards for Total, Planned, In Progress, Completed, Live, and Needs Attention.
  - Identify orders that require attention because of exceeded durations, degraded cycle times, or overdue dates.
  - Expand grouped orders to review individual assignments.
  - Sort across the complete order dataset and move through results with server-backed pagination.
  - Switch progress displays between PDA production entries and detected cycle counts.
  - Select multiple orders for detailed analysis.
  - Enable automatic refresh and save column visibility preferences.

  #### [Hall Plan Kiosk and Display Management](/en/platform-intro/pages/hall-plan)

  Hall Plans can now be configured for unattended production-floor displays.

  - Use a simplified kiosk layout designed for wall-mounted screens.
  - Configure language, machine sorting, visible metrics, zoom, refresh frequency, and page rotation.
  - Choose which production statistics appear in the kiosk navigation.
  - Review display connectivity and last-seen information.
  - Automatically load new frontend builds on unattended displays.
  - Administrators can monitor live and offline Hall Plan devices.

  #### [Knowledge Base Workspace](/en/platform-intro/pages/knowledge-base)

  The Knowledge Base now supports a document workflow and visual Knowledge Graph.

  - Upload files, images, or written notes and monitor their processing status.
  - Search and review stored documents.
  - Review suggested relationships with machines, orders, and products.
  - Confirm or reject suggested links.
  - Explore confirmed and suggested relationships in the Knowledge Graph.

  ### Improvements

  #### [Data Acquisition (PDA)](/en/platform-intro/pages/data-acquisition)

  Search for unplanned operations and assign them directly to a machine without leaving the PDA page.

  #### [Account Sessions](/en/platform-intro/pages/user-profile)

  The user profile shows active sessions, including the device, browser, operating system, IP address, location, and login time. Users can sign out an individual device or all other sessions.
</Update>

<Update label="2026-04-30" description="v1.5.60" tags={["feature", "improvement"]}>
  **UI-Build commit:** `ad93cfa01`

  **Release period:** March–April 2026

  ### New Features

  #### User Permissions Editor

  Administrators can manage page and machine access from the Admin Panel.

  - Open a user record and select **Edit Permissions**.
  - Select the platform pages and machines the user can access.
  - Save the changes so they apply to the user's next session.

  #### Chat History

  The AI assistant has a dedicated page under **Workspace → Chat History**.

  - Reopen saved conversations.
  - Star, rename, or delete conversations.
  - Review answers in the documentation context from which the conversation started.

  ### Improvements

  #### Orders & Products

  The order table includes additional planning and production fields:

  - Customer and priority
  - Planned and actual durations
  - Average cycle time
  - Cycle-time and setup-time deviation
  - Production interval count

  Column visibility preferences are saved for later sessions.

  #### Assignment Planner

  - Search the unassigned operations queue by order, product, or operation.
  - Filter by order tags and priority.
  - Review and edit operation or assignment notes from the planner.

  #### ERP Upload Planner

  - Import order tags with order data.
  - Choose standard or industry-minute interpretation for time fields.
  - Limit an import to orders that already have a machine assignment.
  - Review upload progress and schedule warnings before confirmation.

  #### Data Acquisition (PDA)

  - Operation sequence numbers appear on job chips.
  - Starting or stopping production updates the related order status.
  - An over-production prompt can help operators review order completion.
  - Operation and assignment notes are available from the PDA page.

  #### AI Chat Sidebar

  The assistant can provide documentation-based guidance about the current page, available actions, workflows, and settings.

  <Callout kind="info">
    Page and machine availability depends on the permissions assigned to the user.
  </Callout>
</Update>
