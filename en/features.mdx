## Navigation and View Personalization

Pin frequently used pages in the side navigation and reorder them with drag and drop. Pinned navigation is saved for later sessions.

Supported production views also retain personal display choices. These include Hall Plan version and zoom, Machines filters and sorting, PDA assignment columns and sorting, and Orders & Products column visibility.

## Machine Operations

Machine-oriented pages cover the machine overview, live details, historical analysis, configuration, Data Acquisition (PDA), and alert rules. The related workflows explain setup, live monitoring, history review, and alert-rule management.

## Orders and Planning

Orders & Products provides the starting point for product and production-order work. Scheduler and Assignment Planner support later planning, while Order Detail contains the deeper structure of a single production order.

## Analysis and Workspace

Reporting pages separate timeline-based investigation, longer-term trends, organization-wide statistics, machine comparisons, ranking, and energy peaks. Workspace pages cover Kanban, the Knowledge Base, and Chat History.

## Administration and API Access

The Admin Panel contains shared setup used across the platform. The ERP Upload Planner handles incoming production data. Public integrations use the REST API documented in the **API Reference** tab.
