## Goal

Get an answer about your document or picture, then choose where to keep the file.

## Before You Begin

<Callout kind="info" title="Workflow access">
Admins have access to the assistant. Users and Machine operators need **AI Chats** page access and **AI access** enabled. Keeping files also requires Knowledge Base page access and an Admin to allow the assistant's knowledge base area under **Admin Panel → A.I. → AI assistant**. You can use chat files without that keeping option.
</Callout>

### Preconditions

- Have up to 5 files ready, each up to 25 MB: PDF, Word, Excel, CSV, text or pictures. See [supported formats](/en/platform-intro/pages/knowledge-base#processing).
- Decide what you want to know, such as which checks a work instruction calls for.

## Steps

<Steps>
  <Step title="Open the assistant and add files" icon="arrow-right" title-type="p">
    Open the assistant's side panel, floating window or **AI Chats** page. The assistant on the PDA page works too. Use the paperclip, drop files onto the chat or paste a screenshot into the message box. Each file appears above the box with its name and progress.
  </Step>
  <Step title="Choose where to keep them" icon="arrow-right" title-type="p">
    If **Also keep these files in your knowledge base?** appears, select **Remember my choice** first if you want your choice to apply to future files too. Then choose **Keep in knowledge base** or **Only this chat**. Kept files are **Private**. If you already chose a default in your profile, it applies without asking. If keeping is unavailable, the files stay in the chat.
  </Step>
  <Step title="Check the files and send your question" icon="arrow-right" title-type="p">
    Wait for documents to show **Ready** after **Reading**. Pictures can be sent once uploaded. Read any failure reason and remove the failed file with ×. Write your question and use the paper-plane button at the bottom right to send. You can also send files without text.
  </Step>
  <Step title="Read the answer and open a file" icon="arrow-right" title-type="p">
    The assistant uses your files in its answer. Select a file on your sent message to open the preview. A kept file opens in the knowledge base. To keep an eligible chat file later, open its three-dot menu, **More for this file → Keep in knowledge base**. The **Knowledge base** mark confirms it was kept.
  </Step>
</Steps>

## Decision Points

- Want a different default? Open your profile → **My AI assistant → Files added in the chat**. Choose **Ask each time**, **Keep in my knowledge base** or **Only in the chat**.
- Want colleagues to use a kept file? Follow [review and share a document](/en/platform-intro/workflows/knowledge-base).
- Deleting the conversation? Keep eligible files you still need first. Files used only in that chat are deleted with it; kept files stay. Deletion cannot be undone.

## Expected Result

Your message shows its files, and the assistant uses them in its answer. Files you chose to keep also appear in your knowledge base as private documents.

## Common Problems and Edge Cases

- **Waiting until the file is read**: wait for the document to finish reading before sending.
- **Can't be read** or **No text found**: check the reason beside the file. Failed files are not sent and stay above the box until removed with ×.
- **Picture only**: the assistant can look at the picture in the chat, but it cannot be kept in the knowledge base because no readable text was found.
- No keeping choice or profile setting: check Knowledge Base page access with your Admin and whether the assistant's knowledge base area is allowed. You can still use files in the chat.
- Attached but neither sent nor kept in the knowledge base: these files are removed after about a day. Send the message if you want to keep using its files in the chat.
