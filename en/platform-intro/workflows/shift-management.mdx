## Scheduled Shifts or Active Shifts?

A Shift has start, end, and optional breaks; a Shift group defines weekday patterns. Active shifts are configured per machine and start automatically with machine activity. Switching removes scheduled shifts from today onward. Review [Machine Configuration](/en/platform-intro/pages/machine-configuration) before changing the model; some alert rules do not work with active shifts.

## Decision Points

- Whether a new shift should stand alone or belong to an existing group.

## Expected Result

The platform can use the shift setup for weekly planning and daily machine interpretation.

## Common Problems and Edge Cases

- A shift definition can exist before it is assigned to any machine.
- Editing a shared shift structure may affect multiple machines.
