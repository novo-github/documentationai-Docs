title: "Plan Machine Assignments"
description: "Place unassigned work onto machine queues and reorder existing planned work."
---

## Goal

Turn unassigned work into machine-specific planned queues.

## Before You Begin

Planners and admins who decide where work should run next.

<Callout kind="info" title="Workflow access">
- Roles: Admin, Manager
- Entry points: `/assignment-planner`
</Callout>

Begin on the [Assignment Planner page](/en/platform-intro/pages/assignment-planner).

### Preconditions
- Machines are available for planning.
- Orders or operations already exist in the system.

## Steps

<Steps>
  <Step title="Filter the visible hall or machine list" icon="arrow-right" title-type="p">
    Filter the visible hall or machine list if needed.
  </Step>
  <Step title="Search the unassigned work list to find the right" icon="arrow-right" title-type="p">
    Search the unassigned work list to find the right job.
  </Step>
  <Step title="Drag work onto a machine column or open the" icon="arrow-right" title-type="p">
    Drag work onto a machine column or open the assignment confirmation flow.
  </Step>
  <Step title="Reorder work" icon="arrow-right" title-type="p">
    Reorder work inside the machine queue to adjust planned sequence.
  </Step>
  <Step title="Update key details" icon="arrow-right" title-type="p">
    Update key details such as status, dates, or priority when needed.
  </Step>
  <Step title="Let the planner save the queue changes back to the" icon="arrow-right" title-type="p">
    Let the planner save the queue changes back to the platform.
  </Step>
</Steps>

## Decision Points

- Which machine should take the job.
- Whether a job should stay unassigned, move to another machine, or be removed from a queue.

## Expected Result

The machine queue reflects the latest planning decision and related order details stay aligned.

## Common Problems and Edge Cases

- Only a limited number of machines can be shown at once.
- If filters hide all machines, the planner shows an empty planning surface.
- Removing an assignment sends the work back out of the planned queue rather than completing it.
