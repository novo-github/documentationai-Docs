## Goal

Create a machine record with the basic information needed for monitoring and planning.

## Before You Begin

<Callout kind="info" title="Workflow access">
- Entry points: `/machines`
</Callout>

Begin on the [Machines page](/en/platform-intro/pages/machines).

### Preconditions
- The user has admin access.
- Halls and shift groups already exist if the machine should be placed immediately.

## Steps

<Steps>
  <Step title="Open the machine creation flow" icon="arrow-right" title-type="p">
    Open the machine creation flow from the Machines page.
  </Step>
  <Step title="Enter the machine name and identification details" icon="arrow-right" title-type="p">
    Enter the machine name and identification details.
  </Step>
  <Step title="Add optional tags or an image" icon="arrow-right" title-type="p">
    Add optional tags or an image if the team uses them for filtering and recognition.
  </Step>
  <Step title="Assign the machine to a hall and shift group" icon="arrow-right" title-type="p">
    Assign the machine to a hall and shift group.
  </Step>
  <Step title="Enable energy monitoring" icon="arrow-right" title-type="p">
    Enable energy monitoring only if that machine is connected for energy tracking.
  </Step>
  <Step title="Finish the setup" icon="arrow-right" title-type="p">
    Finish the setup and return to the machine list.
  </Step>
</Steps>

## Decision Points

- Whether the machine should be placed in a hall immediately or left for later.
- Whether energy monitoring is needed on day one.

## Expected Result

The machine appears in the platform and can be opened in machine-specific pages.

## Common Problems and Edge Cases

- Required fields may block completion until they are filled in.
- If halls or shift groups are missing, the machine can be created with partial setup and finished later.
- A machine without planning data may appear in lists before it is fully ready for scheduling.
