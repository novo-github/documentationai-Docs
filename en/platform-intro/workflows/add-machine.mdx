## Before You Begin

**Who can do this: Admin only.** Start at **Admin Panel → Machines → Add Machine**, route `/admin-panel`. Have the name, type, hall, and any shift-group information ready. Machine creation is also documented from the Machines page.

## Basics → Settings & Media → Review

1. In **Basics**, enter identification details and choose **Kind**: Machine or Work center, plus the machine type.
2. In **Settings & Media**, set the applicable hall, shift group, tags, and image.
3. In **Review**, check the record and save it.
4. Open [Machine Configuration](/en/platform-intro/pages/machine-configuration) to attach an AVA and configure ratings, timeline rules/ranges, features, optional energy monitoring, and PDA Assistant warnings.
5. For a Machine, verify that the AVA is mapped before expecting live readings.

## Choose the Shift Model

In the machine setup, use **Shifts → Active shift** if shifts should start with idle, production, or preparation. Set **Minimum shift length**, **Stop that ends a shift**, and **Maximum shift length**. All values must be greater than 0, neither the minimum nor the stop length may exceed the maximum, and the maximum is 24 hours. The shift group is not used while this is enabled. Leave it off for scheduled shifts. See [active shift settings](/en/platform-intro/pages/machine-configuration) before saving.

## Expected Result and Common Problems

The entry appears in [Machines](/en/platform-intro/pages/machines) and can receive planned work. A Machine saved without an AVA collects no sensor data until an AVA is mapped. A Work center intentionally has no AVA, sensor KPIs, state-counter inclusion, or sensor-based alert/Automator triggers.

If required fields block saving, complete them. Finish missing hall or shift setup before relying on those planning views. See [Configure a Machine](/en/platform-intro/workflows/machine-configuration).
