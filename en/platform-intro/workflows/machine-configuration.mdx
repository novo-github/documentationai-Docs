## Goal

Adjust how a machine is identified, monitored, measured, and interpreted by the platform.

## Before You Begin

<Callout kind="info" title="Workflow access">
- Required access: Admin only.
- Entry points: `/machine/config`, `/machine/:id/config`
</Callout>

Begin on the [Machine Configuration page](/en/platform-intro/pages/machine-configuration).

### Preconditions
- The machine already exists, unless the user is creating one through the new-machine route.

For a **Work center**, use the kind-switching steps below and skip AVA and sensor-measurement setup.

## Steps

<Steps>
  <Step title="Open the machine configuration" icon="arrow-right" title-type="p">
    For an existing machine, select the **Machine Settings** gear in its detail header. Only administrators see it. Settings open in the same tab; the browser’s back button returns to the machine.
  </Step>
  <Step title="Review the basic information" icon="arrow-right" title-type="p">
    Review the Basic Information tab and confirm the machine identity, hall, and shift group.

    If the sensor receives power only while the machine is switched on, enable **Sensor powered by machine** in **Basic Info**. A missing sensor signal will then appear as **machine off** instead of **unknown**. Save the tab before continuing.
  </Step>
  <Step title="Connect AVA devices and set their priority" icon="arrow-right" title-type="p">
    Open **AVA Assignments** and select the AVA device to connect to this machine. If several devices are connected, drag them up or down to set their priority.

    Correct any invalid or duplicate entries identified before saving, then save the tab.
  </Step>
  <Step title="Configure energy monitoring" icon="arrow-right" title-type="p">
    Configure energy monitoring if the machine supports it.
  </Step>
  <Step title="Set ratings" icon="arrow-right" title-type="p">
    Set ratings so dashboards can compare live results against target expectations.
  </Step>
  <Step title="Define timeline ranges and timeline rules" icon="arrow-right" title-type="p">
    Define timeline ranges and timeline rules so machine states are interpreted consistently.
  </Step>
  <Step title="Adjust machine-specific feature settings" icon="arrow-right" title-type="p">
    Adjust feature settings where the platform exposes machine-specific analytical thresholds.
  </Step>
  <Step title="Save changes on each tab before leaving it" icon="arrow-right" title-type="p">
    Save changes on each tab before leaving it.
  </Step>
</Steps>

## Set Simultaneous Machine Capacity

1. As an administrator, open the machine’s basic information and find **Planning → Jobs in parallel**.
2. Enter how many assignments it can run together, as a whole number from 1 to 100. Match actual capacity, not the number waiting in the queue.
3. Save the tab, then review expected times in [Assignment Gantt](/en/platform-intro/pages/assignment-gantt). The Forecaster uses this capacity when planning simultaneous work.

## Review Kind, Shift Model, and Warnings

Only admins edit this setup. Confirm whether the entry is a sensor-connected **Machine** or a sensorless **Work center**. Converting to Work center unassigns AVAs and stops sensor KPIs.

Use the steps below to change **Active shift** and review the effect on today's shifts. Check alert-rule notices for rules that do not work with active shifts.

Configure **PDA Assist** using the warning setup steps below. See [Machine Configuration](/en/platform-intro/pages/machine-configuration) for rules, duration buckets, ratings, and feature fields.

## Switch Between Machine and Work Center

<Steps>
  <Step title="Choose the kind" icon="arrow-right" title-type="p">
    As an administrator, open **Basic Info** in the configuration and choose **Kind → Work center** for a workplace without an AVA.
  </Step>
  <Step title="Review the devices being removed" icon="arrow-right" title-type="p">
    If AVAs are assigned, **Switch to work center?** lists them. Confirm **Unassign and switch** only if they should be unassigned and all KPI calculation should stop. Save the change. AVA assignment is unavailable for work centers.
  </Step>
  <Step title="Check work and rules" icon="arrow-right" title-type="p">
    Open **Machines → Work centers** to review running and planned orders. Check alert and Automator rules: conditions based on machine or sensor measurements never trigger for this workplace.
  </Step>
  <Step title="Reconnect a sensor if changing back" icon="arrow-right" title-type="p">
    To collect readings again, select **Kind → Machine** and save. Then assign an AVA in the AVA tab. Changing the kind alone does not start data collection.
  </Step>
</Steps>

## Switch Between Active and Scheduled Shifts

<Steps>
  <Step title="Choose how shifts start" icon="arrow-right" title-type="p">
    As an administrator, open **Shifts** in the machine configuration. Enable **Active shift** to start shifts with idle, production, or preparation. Leave it off to use the assigned shift group's schedule.
  </Step>
  <Step title="Set when active shifts end" icon="arrow-right" title-type="p">
    Set **Minimum shift length**, **Stop that ends a shift**, and **Maximum shift length** in hours greater than 0. Neither the minimum nor the stop length may exceed the maximum, which is at most 24 hours. Before the minimum is reached, shorter stops stay inside the shift as off time. Afterward, the first stop ends it. At the maximum, a new shift starts even if work continues.
  </Step>
  <Step title="Review the switch and save" icon="arrow-right" title-type="p">
    Enabling removes scheduled shifts from today onward but keeps shifts already recorded today. The shift group stays assigned and unused. Disabling ends the running active shift immediately and creates scheduled shifts from the assigned group from today. Check that group before switching back. Review the confirmation, select **Continue**, and save the tab.
  </Step>
  <Step title="Check the machine and its alerts" icon="arrow-right" title-type="p">
    Check the **Active shift** badge and the note in the shift planner. Review the machine's alert rules for notices that they will skip machines with active shifts.
  </Step>
</Steps>

## Set Up and Copy PDA Assist

<Steps>
  <Step title="Choose the assistance you need" icon="arrow-right" title-type="p">
    As an administrator, open **PDA Assist** and tick **Interval assist**. With no saved options, start and end correction are preselected. Review them before saving. Under **Start time** and **End time**, set the production and setup groups separately. For setup, choose the previous order’s end, switch-on, or production stop as appropriate. Select **When production started** if setup should end at production start. Review gap conditions in [Machine Configuration](/en/platform-intro/pages/machine-configuration).
  </Step>
  <Step title="Choose when to ask" icon="arrow-right" title-type="p">
    Under **How changes are applied**, choose **Ask the operator** or **Pick the best automatically**. Set the automatic and asking limits in hours. Older times between those limits always require a choice. Open **How are the times chosen?**, choose an example, and use **Back** and **Next** to check the result against this machine’s limits.
  </Step>
  <Step title="Check automatic ending" icon="arrow-right" title-type="p">
    If using **Auto-end forgotten intervals**, set the off or idle condition and waiting time. It affects production only and does not book quantities. To stop automatic ending, turn this option off. Check whether it comes before the off-machine warning.
  </Step>
  <Step title="Set warnings and sound" icon="arrow-right" title-type="p">
    Tick **Warnings**. With no saved options, three recommended warnings are preselected. Review each warning’s delay and severity. Enable **Alarm sound** and the speaker for each warning that should sound. **Info** stays silent. Set **Snooze** and test the volume. Open each warning’s information icon. Compare **When it appears** with **What the operator sees** before saving; the preview uses your unsaved choices. Check whether automatic ending comes before the warning.
  </Step>
  <Step title="Save or reset" icon="arrow-right" title-type="p">
    Select **Save** for this machine. To restore one section, open it, select **Reset to defaults**, and confirm. Its on/off selection stays unchanged. Select **Save** to keep the reset.
  </Step>
  <Step title="Copy both sections if needed" icon="arrow-right" title-type="p">
    Select **Copy to other machines…** and choose destinations. Review both sections, including unsaved changes: both replace the destination settings. Confirm and check success and failure counts. Save the current machine separately.
  </Step>
</Steps>

Open the machine’s PDA page to check the result. Tap **PDA Assist** at the right edge to see what is enabled for the operator. Follow [Run Data Acquisition](/en/platform-intro/workflows/data-acquisition) for choices and warning actions. For reason selection, follow [Create and Manage Downtime Reasons](/en/platform-intro/workflows/timeline-reason-creation).

## Decision Points

- Which tabs matter for the specific machine.
- Whether a change is foundational setup or an analytical fine-tuning step.

## Expected Result

The machine behaves correctly across monitoring, reporting, alerting, and planning views.

## Common Problems and Edge Cases

- Some tabs stay unavailable until the machine exists.
- Unsaved tab changes can be lost if the user navigates away too early.
- If AVA entries cannot be saved, review and correct the flagged invalid or duplicate entries.
- Enable **Sensor powered by machine** only when the sensor loses power with the machine; otherwise a missing signal could be mistaken for a shutdown.
