## Before You Begin

**Who can do this: Admin only.** Start at [Admin Panel](/en/platform-intro/pages/admin-panel), route `/admin-panel`. Have the person's email, required role, pages, and machines ready.

## Invite a Team Member

1. Open **Invite Team Members**.
2. Enter the email and select the role.
3. Send the invite and review it in the user area.
4. Resend it when needed, or revoke it when it should no longer be usable. A revoked invitation link stops working immediately.

## Set Page and Machine Access

1. Open the user in **Users** and choose **Edit Permissions**.
2. Select **Full Access** or a specific **Page Access** list. Full Access remains subject to the role's restrictions; an empty list grants no grantable pages.
3. Set **Machine Access** separately to all machines or a selected list.
4. Save. Ask the user to recheck in their next session.

**Example:** Give a planner Assignment Planner access plus the machines they plan. Giving only the page does not give access to every machine.

## Request an Email Change for a User

For a user who is not an operator, select **Change email** in user management. Enter **New email** and select **Send verification**. Use this action instead of editing the address in the user form. Ask the user to open the link at the new address and select **Confirm email change**. Until then, the current address stays active. The pending notice lets you **Resend** after the displayed wait or **Cancel change**. Follow [Change Your Email Address](/en/platform-intro/workflows/change-email).

## Operators and Promotion

Use [Manage Operators](/en/platform-intro/workflows/operator-management) to create or recover an operator account. Copy or download the one-time generated password. Generating a replacement ends active sessions; deactivation ends access immediately while preserving history.

**Promote to user** gives access to all machines regardless of the previous machine list. Review that effect before promoting. Operators never receive Hall Plan, Orders & Products, or Alert Rules.

## Expected Result and Common Problems

The person has the intended role, pages, and machines. **Unauthorized** indicates a page restriction; **No machine access — contact admin** indicates the machine list. Admin-only pages cannot be granted to a non-admin. See [roles and access](/en/platform-intro/concepts/roles-and-access).
