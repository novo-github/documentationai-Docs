## Overview

**Access: All roles.** Route: `/roadmap`.

Roadmap is Novo AI's public feature plan. Columns are **Ideas**, **Planned**, **In progress**, and **Released**. Users can upvote items to show interest.

## Use Roadmap and Feedback Together

Find an existing idea before submitting a new request. A planned or in-progress item is not yet a released feature; rely on the displayed status rather than assuming availability.

Use [Feedback](/en/platform-intro/pages/feedback) for bugs, improvements, or feature requests that need a conversation. Check the [changelog](/en/changelog) for documented release information.
