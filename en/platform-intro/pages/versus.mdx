## Overview

**Access:** Admin or Page Access `versus`, with relevant Machine Access. [Roles and access](/en/platform-intro/concepts/roles-and-access).

Help users compare machines directly under the same time context.

Users open it from the main navigation.

## Access

<Callout kind="info" title="Access details">
- Visibility: Protected
- Primary routes: `/versus`
</Callout>

## What You Can See

- Machine selectors and date controls.
- Comparative charts and summary blocks for the chosen machines.

## What You Can Do

- Choose the machines to compare.
- Change the time window.
- Review which machine is performing better or worse on the selected metrics.

## 1v1, AVL, and PRO

**1v1 / 1 V 1** is an older name for Versus. **AVL** is Availability; **PRO** is Performance, not Production. Select the same period and shift scope for each machine and distinguish target ratings from actual values. See [calculations](/en/platform-intro/concepts/calculations#oee) for the platform-specific time definitions.

## Main Entities

- Machine
- Time Range
- Performance Metric

## Outcomes and Limits

### Common Outcomes
- Users identify gaps between machines and decide where to investigate next.

### Limits and Empty States
- The page is only useful when the selected machines have comparable data.
