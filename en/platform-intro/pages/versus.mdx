## Overview

**Access:** Admin or Page Access `versus`, with relevant Machine Access. [Roles and access](/en/platform-intro/concepts/roles-and-access).

Help users compare machines directly under the same time context.

Users open it from the main navigation.

## Access

<Callout kind="info" title="Access details">
- Visibility: Protected
- Primary routes: `/versus`
</Callout>

## What You Can See

- Machine selectors and date controls.
- Comparative charts and summary blocks for the chosen machines.

## What You Can Do

- Choose the machines to compare.
- Change the time window.
- Review which machine is performing better or worse on the selected metrics.

## 1v1, AVL, and PRO

**1v1 / 1 V 1** is an older name for Versus. **AVL** is Availability; **PRO** is Performance, not Production. Select the same period and shift scope for each machine and distinguish target ratings from actual values. See [calculations](/en/platform-intro/concepts/calculations#oee) for the platform-specific time definitions.

## Compare Machines with Active Shifts

Comparison timelines account for shifts that start and end with machine activity. When comparing these machines with machines on scheduled shifts, check each machine's shift period. Their shift boundaries can differ even on the same day. See [active shift settings](/en/platform-intro/pages/machine-configuration).

## Read Downtime Reason Codes

Downtime chart labels include a reason's code when one is set. Short labels may be cut off; hover over a bar or pie slice to read the full name, code, and category. Categories help identify reasons; the charts still group by reason.

See [downtime reason settings](/en/platform-intro/pages/admin-panel) for how administrators maintain these labels.

When assigning a reason in the timeline, the picker offers only that machine’s available reasons, alphabetically, with any code before the name. **Remove label** clears a reason. Older labels remain visible even when they are no longer selectable.

## Outcomes and Limits

### Common Outcomes
- Users identify gaps between machines and decide where to investigate next.

### Limits and Empty States
- The page is only useful when the selected machines have comparable data.
