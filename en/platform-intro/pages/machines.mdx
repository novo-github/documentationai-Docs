## Overview

**Access:** All roles; only permitted machines are visible. [Roles and access](/en/platform-intro/concepts/roles-and-access).

Give users a fast overview of the available machines and their current production state.

This is the main dashboard route for signed-in users and the default landing page after login for most roles.

## Access

<Callout kind="info" title="Access details">
- Visibility: Protected
- Primary routes: `/machines`
</Callout>

## What You Can See

- Summary counters for machine states such as production, idle, off, and preparation.
- Machine cards with names, hall context, status information, and alerts.
- Sorting and display preferences for which metric is emphasized.

## What You Can Do

- Filter the board by state or contextual tags.
- Sort machines by name or key performance metrics.
- Open a machine to reach its detail page.
- Start machine creation from here if the user has the right access.

Filters and sorting are restored when the user returns to the Machines page.

## Today's Orders and the Queue

**Orders today** (previously **Live orders**) shows steps worked today, with running work first and recent work after it. Cards include the order, product, step number, status, times, and order and operation priorities. Only running steps have a coloured edge. A step that began yesterday keeps its actual start date and time.

**Up next** (previously **Planned orders**) shows the first 10 waiting steps in the machine's queue order, including work planned for other days. Numbered badges show each step's place. The cards show planned times. Running work stays in **Orders today**. The queue view is hidden when nothing is waiting; open the [machine page](/en/platform-intro/pages/machine-details) for the whole queue.

Each list shows two cards at a time. Longer lists advance every 8 seconds, or you can scroll by hand. A single running card stays visible; when several steps run together, they lead the list. Movement pauses while you hover, use keyboard focus, or interact with the list. Reduced-motion preferences turn automatic movement off. The position count shows where you are in the list; for **Up next**, the total includes waiting steps beyond the first 10.

Click a card to open the order in a new tab if you have order-page access. Today's lists refresh every minute. Follow [Monitor a Machine Live](/en/platform-intro/workflows/live-machine-monitoring).

## Distinguish Machine States with Patterns

The machine status legend explains the colors used for each state. Enable **Accessibility patterns** in the legend to add a visual pattern alongside the existing colors:

| State | Pattern |
| --- | --- |
| Idle | Dots |
| Off | Diagonal lines |

The setting applies wherever machine status is shown, making these states easier to distinguish without relying on color alone.

Select **See how this looks** to compare the same shift timeline with and without patterns, including a simulation of color blindness. Use the preview to check whether the display is easier for you to read.

If a sensor switches off together with its machine, the [Sensor powered by machine setting](/en/platform-intro/pages/machine-configuration#sensors-powered-by-the-machine) lets a missing signal be displayed as **machine off** instead of **unknown**.

## Machine or Work Center?

Choose **Work centers** in the view switch to see workplaces without an AVA. Their cards show **Orders today** and **Up next**. Switch back to **Machines** for machine states and KPIs.

**Kind** distinguishes **Machine** from **Work center**. Work centers are excluded from state counters and sensor analytics. Administrators can change the kind; converting a machine removes its AVA assignments and stops KPI calculation. See [Work Centers](/en/platform-intro/pages/work-centers) for setup and limits.

## State Colors and Short Captions

| State | German label | Color | Meaning |
| --- | --- | --- | --- |
| Production | Produktion | Green | Producing. |
| Idle | Leerlauf | Orange | On but not producing. |
| Off / Stopped | Aus / Gestoppt | Red | Off. |
| Preparation | In Vorbereitung | Blue | Setting up. |
| Unknown | Unbekannt | Grey | No usable signal. |

Ring gauges use **OEE**, **AVL** (Availability), and **PRO** (Performance). The caption under the center figure identifies the displayed metric. **PRO does not mean production.** For definitions, use [calculations](/en/platform-intro/concepts/calculations#oee).

## Understand Active Shifts

**Active shift** identifies a machine whose shifts follow machine activity. A shift starts at idle, production, or preparation and ends according to the machine's shift settings. Its assigned shift group is not used. See [Machine Configuration](/en/platform-intro/pages/machine-configuration).

**Waiting for the next active shift** or **waiting for machine start** means the next shift has not started yet. It starts automatically when the machine begins idle, production, or preparation. Until then, planned shifts from the assigned shift group are shown. This display does not switch off active shifts.
