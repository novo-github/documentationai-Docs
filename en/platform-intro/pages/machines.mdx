## Overview

Give users a fast overview of the available machines and their current production state.

This is the main dashboard route for signed-in users and the default landing page after login for most roles.

## Access

<Callout kind="info" title="Access details">
- Roles: Admin, Manager, Operator
- Visibility: Protected
- Primary routes: `/machines`
</Callout>

Operators, managers, and admins.

## What You Can See

- Summary counters for machine states such as production, idle, off, and preparation.
- Machine cards with names, hall context, status information, and alerts.
- Sorting and display preferences for which metric is emphasized.

## What You Can Do

- Filter the board by state or contextual tags.
- Sort machines by name or key performance metrics.
- Open a machine to reach its detail page.
- Start machine creation from here if the user has the right access.

## Main Entities

- Machine
- Hall
- Shift
- Alert

## Outcomes and Limits

### Common Outcomes
- Users identify which machines need attention.
- Users jump into a machine detail page for deeper work.

### Limits and Empty States
- Users with no machine access can see an informational empty state instead of machine cards.
- Some creation or admin actions depend on role.
