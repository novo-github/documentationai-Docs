## Overview
Give users a detailed, date-aware view of one machine’s live or recent activity.

Users open this page by selecting a machine from the Machines page.

## Access
<Callout kind="info" title="Access details">
- Roles: Admin, Manager, Operator
- Visibility: Protected
- Primary routes: `/machines/:machineId`
</Callout>

Operators, managers, and admins.

## What You Can See
- Date controls and shift tabs.
- KPIs, cycle-related views, and timeline sections.
- Alert context and related machine actions.

## What You Can Do
- Change the selected date.
- Focus on a specific shift or all shifts.
- Open PDA, machine history, or alert rules.
- Review current machine state and recent events.

## Main Entities
- Machine
- Shift
- Timeline Event
- Alert
- Assignment

## Outcomes and Limits
### Common Outcomes
- Users understand what the machine is doing and decide the next action.

### Limits and Empty States
- A selected date with little data can make parts of the page look sparse.
