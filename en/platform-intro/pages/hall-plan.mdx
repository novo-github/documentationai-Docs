## Overview

Review production across a hall on your own screen or on a shared production-floor display. A kiosk is a simplified view for a screen that runs without someone continuously operating it.

Users open a hall-specific route, often from a shared link or display device.

## Access

<Callout kind="info" title="Access details">
- Visibility: Hall-specific displays can be public; display configuration and device monitoring are administrative actions
- Primary routes: `/hallPlan/:id`
</Callout>

## What You Can See

- Machines, current states, active orders, and produced pieces across the hall.
- OEE, availability, performance, and machine-time metrics.
- Live information alongside previous-shift information.
- A compact, paginated machine view for large halls.
- Display connectivity and last-seen information for managed devices.

## What You Can Do

- Review the hall at a glance.
- Select which production metrics appear.
- Choose the Hall Plan display version and zoom level.
- Configure kiosk language, machine sorting, visible metrics, refresh frequency, and page rotation.
- Choose which production statistics appear in kiosk navigation.
- Monitor live and offline Hall Plan devices.

## Understand the Page

### Choose the Information on Your Display

In the Hall Plan display settings, choose the view version, zoom, visible production metrics, and machine sorting. Select a language and refresh frequency that suit the people using the display. Page rotation lets an unattended screen move through the configured views, while the kiosk navigation settings determine which production statistics are available.

Review current machine states, active orders, and produced pieces together with OEE, availability, performance, and machine times. Compare live information with the previous shift and use planned and actual setup, production, and cycle times to understand deviations. Company branding helps identify the shared hall display.

### Check Display Connectivity

Administrators can review whether a managed display is live or offline and when it last reported activity. These indicators describe the display's connection, not the production state of a machine. If a screen appears out of date, check its connectivity and last-seen information before interpreting the displayed production values.

## Outcomes and Limits

### Common Outcomes
- Users understand the current hall-wide production picture quickly.
- Unattended displays rotate through the configured production view and load application updates automatically.

### Limits and Empty States
- The page depends on a valid hall route and visible machine data.
- Device status depends on the display reporting its connectivity and last-seen information.
