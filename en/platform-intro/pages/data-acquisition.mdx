## Overview

Support live shop-floor execution and event recording for a single machine.

Users usually open it from the Machine Details page.

## Access

<Callout kind="info" title="Access details">
- Visibility: Protected
- Primary routes: `/machines/:machineId/dataAcquisition`
</Callout>

## What You Can See

- Assignment lists and live order context in open-assignment or time-window views.
- Personalized assignment columns, ordering, and sorting.
- Start, preparation, and stop controls.
- Interval history, notes, tickets, and knowledge context.

## What You Can Do

- Start or stop work.
- Record produced quantity, material scrap, and work scrap when stopping or continuing an interval.
- Create or use live orders.
- Search for unplanned operations and assign them directly to the machine.
- Configure the information and ordering shown on assignment cards.
- Apply timeline reasons and review related support content.

## Main Entities

- Machine
- Assignment
- Interval
- Production Order
- Ticket

## Outcomes and Limits

### Common Outcomes
- The machine’s production story is captured in a detailed, shift-level form.
- Recorded totals include the submitted scrap quantities.

### Limits and Empty States
- Users need the right live assignment or order context before the page is fully useful.
- The page warns users before production starts when another assignment is already running.
