## Overview

**Access:** Only Administrators and Super Admins can open **Report archive**. Other users do not see it.

Open **Reports** in the side menu. At the top of Timeline Analysis or Trend Analysis, select the archive button with the tooltip **Report archive** next to the **Timeline** / **Trend** switch.

The archive brings together reports created on request and scheduled reports. Use it to find an existing report or return to one that is still being created.

## What You Can See

Report types are **Weekly**, **Monthly**, and **Export**. Weekly and monthly analytics reports are Excel workbooks. The source shows **Scheduled** or **By user**.

| Status | Meaning |
| --- | --- |
| **Queued** | Waiting for creation to begin. |
| **Building** | Being created; the file is not ready yet. |
| **Ready** | Created and ready to download. |
| **Failed** | Creation did not finish successfully. |

An email count shows how many emails were sent. **Not emailed** means the report has not been sent by email; check its creation status separately.

## What You Can Do

- Filter by machine, source, and period. Use **All machines** or **All sources** to broaden your search.
- Choose **Last 30 days**, **Last 90 days**, **This year**, **Any time**, or **Custom range**.
- Use **Previous page** and **Next page** to browse the results.
- Download an available file once the report is **Ready**.

Follow [Download and Update Reports](/en/platform-intro/workflows/reports).

## Rebuild with Current Data

Select **Rebuild with current data** on an existing report to check it against current production records. **Refreshing** means this check is still underway.

If the contents changed, the report is updated. Its version and update time help you recognize the new result. If nothing changed, you see **Checked against current data: nothing changed.** The last-checked time tells you when the check happened.

If refreshing fails, the previous version stays available. For example, after production entries are corrected, rebuild the report before using it to review the period again.

## Scheduled Reports and Email

Scheduled weekly and monthly reports can be delivered by email. Check the report's source and email count to distinguish a scheduled report from one requested by a user, and to see whether it was emailed.

After a delivery problem, the Watchmen team can manually resend the latest scheduled weekly report for the last completed week, the latest scheduled monthly report for the last completed month, or both. Only recipients missed by the failed delivery receive it; anyone who already received the report gets no second email. Redelivery is not automatic, and customers cannot start it themselves.

In the meantime, Administrators and Super Admins can download the ready report from **Report archive**. The email count shows sent emails; check the report’s status separately.

## Limits and Empty Results

**No reports found.** means no reports match the current selection. Broaden the filters before requesting another report. **No files available** means there is no file to download for that report.

If a report takes longer than usual, Administrators and Super Admins can return to the archive later. It appears there as soon as it is ready. Other users should try the export again later. If loading or downloading fails, try again. A failed refresh leaves the previous report available.
