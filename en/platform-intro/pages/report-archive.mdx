## Overview

**Access:** Only Administrators can open **Report archive**. Other users do not see it.

Open **Reports** in the side menu. At the top of Timeline Analysis or Trend Analysis, select the archive button with the tooltip **Report archive** next to the **Timeline** / **Trend** switch.

The archive brings together reports created on request and scheduled reports. Use it to find an existing report or return to one that is still being created.

## What You Can See

Report types are **Weekly**, **Monthly**, and **Export**. Weekly and monthly analytics reports are Excel workbooks. The source shows **Scheduled** or **By user**.

| Status | Meaning |
| --- | --- |
| **Queued** | Waiting for creation to begin. |
| **Building** | Being created; the file is not ready yet. |
| **Ready** | Created and ready to download. |
| **Failed** | Creation did not finish successfully. |

An email count shows how many emails were sent. **Not emailed** means the report has not been sent by email; check its creation status separately.

## What You Can Do

- Filter by machine, source, and period. Use **All machines** or **All sources** to broaden your search.
- Choose **Last 30 days**, **Last 90 days**, **This year**, **Any time**, or **Custom range**.
- Use **Previous page** and **Next page** to browse the results.
- Download an available file once the report is **Ready**.

Follow [Download and Update Reports](/en/platform-intro/workflows/reports).

## Recognize the Report Version

**Version 2** beside the period identifies the new report layout. Rows without this badge use Version 1. Point to the badge to read:

> **Report Version 2, the new layout. Each person chooses Version 1 or 2 in their profile under Newsletter report version.**

Scheduled reports in both versions can appear for the same period when subscribers choose different versions. Compare the contents in [Report Versions](/en/platform-intro/pages/report-versions).

## Rebuild with Current Data

Every scheduled report is checked automatically once, 3 days after it was sent. If the data changed, the report gets a new revision. If nothing changed, it stays as it is. This is why a weekly report can show **Revision 2** even if nobody rebuilt it manually.

As an Administrator, you can also select **Rebuild with current data** at any time to check an existing report against current production records. **Refreshing** means this check is still underway.

If the contents changed, the report is updated. The update line says **Revision**, for example **Revision 3, updated …**. The number identifies the updated report; **Version 2** beside the period identifies its layout. A report can therefore show both **Version 2** and **Revision 3**. A report that has never been updated shows no revision line.

Point to the revision text to read:

> **Rebuilt with newer data. Downloads here are always the latest revision. Emails that were already sent are not sent again.**

If nothing changed, you see **Checked against current data: nothing changed.** **Last checked** shows when a later check found nothing new. It is hidden when the check and update show the same minute.

If refreshing fails, the previous revision stays available. You see **Refresh failed, the previous revision is still available: …** For example, after production entries are corrected, rebuild the report before using it to review the period again.

## Scheduled Reports and Email

Choose **Version 1** or **Version 2** in your profile → **Newsletter Preferences** card → **Newsletter report version**. Each person receives their chosen version in one report email per week or month. Switching in the middle of a week does not cause a second email. You may also receive an introduction email with two **Version 2** attachments in your language: last week's report first, then last month's. The email names both periods. Receiving the email does not change your preference. Both reports also appear in the archive as scheduled **Version 2** reports. See [Report Versions](/en/platform-intro/pages/report-versions#confirm-your-choice-from-an-email).

Scheduled weekly and monthly reports can be delivered by email. Check the report's source and email count to distinguish a scheduled report from one requested by a user, and to see whether it was emailed.

After a delivery problem, the Watchmen team can manually resend the latest scheduled weekly report for the last completed week, the latest scheduled monthly report for the last completed month, or both. Only recipients missed by the failed delivery receive it; anyone who already received the report gets no second email. Redelivery is not automatic, and customers cannot start it themselves.

In the meantime, Administrators can download the ready report from **Report archive**. The email count shows sent emails; check the report’s status separately.

## Limits and Empty Results

**No reports found.** means no reports match the current selection. Broaden the filters before requesting another report. **No files available** means there is no file to download for that report.

If a report takes longer than usual, Administrators can return to the archive later. It appears there as soon as it is ready. Other users should try the export again later. If loading or downloading fails, try again. A failed refresh leaves the previous revision available.
