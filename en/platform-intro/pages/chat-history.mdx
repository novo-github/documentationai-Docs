## Overview

**Access:** Admins always have access. Users and Machine operators need **AI Chats** in their page access, and an Admin must not have switched off their **AI access**. [Roles and access](/en/platform-intro/concepts/roles-and-access).

Let users revisit prior AI conversations and continue them when needed.

Users open it from the Workspace section in the main navigation.

## What You Can See

- A list of recent and starred conversations.
- The full message thread for the selected conversation.
- Controls for search, renaming, starring, and deleting conversations.

Your chat title follows the language of your question. If that language is unclear, it follows your interface language.

## What You Can Do

You can also ask from **Help & Support → Ask the AI assistant**. Enter a question and choose **Ask**, or select an example question. The assistant opens and sends it once ready. Text already typed in the chat box stays there. If you close the assistant before the question is sent, it waits in the box for you to send yourself. See [Get Help for Your Current Page](/en/platform-intro/workflows/help-support).

- Start a new conversation.
- Continue an existing conversation.
- Search conversation titles.
- Rename, star, copy, or delete conversation entries.

## What the Assistant Can Do

Ask about the Watchmen guide or company data your Admin allows. The assistant sees only what you may see. It can find colleagues by name; Admins also see their email addresses. It can open pages, fill in forms and propose changes for you to review.

## Learn with a Guide

An empty chat offers **Guides for this page**, or **Guides for you** if none fit the page. **See all guides** opens the guides panel. The AI assistant can also suggest a guide below an answer. The card shows the guide’s title, estimated time, progress if already started, and a short reason. Use the round play button with the tooltip **Start**, or **Continue** for a guide in progress, or choose **Not now**. The suggestion waits for your choice. Starting a guide closes the assistant side panel. See [Interactive Guides](/en/platform-intro/pages/interactive-guides).

While you have personal AI credits from guide points, the chat shows **Your credits:** with the amount and expiry date. Personal credits are used before company credits. While you have them, you can keep using the AI assistant even when the company’s credits or your monthly limit (**Limit per person** or your individual limit set by an Admin) are used up. Their use does not count toward that limit.

**Ask AI** in ⓘ help gives you an explanation at no credit cost. On the PDA page, the answer appears in a bottom bar and is not saved in your chats. On other pages, it opens the assistant side panel and stays in your chats; questions you type afterwards use credits as usual. [Help on every page (ⓘ)](/en/platform-intro/concepts/field-help).

## Write a Message and Read the Answer

The message box has the same layout in the side panel, floating window and AI chats page. Write at the top. Choose the answer mode at the bottom left. At the bottom right, use the paperclip to attach files, the microphone to dictate, and the white paper-plane button to send. The [Knowledge Base note box](/en/platform-intro/pages/knowledge-base) uses the same button style.

Answers appear as open text with spacing and headings, with a thin line and dot beside each answer. The AI chats page uses more of the screen width for answers.

<a id="dictation" />

### Speak Instead of Typing

Use the microphone to dictate. You can stop earlier, or recording stops by itself after 2 minutes and turns what you said into text. In the last 15 seconds, the timer shows the approaching limit with **Recording stops by itself at 02:00.** This limit applies to dictation throughout the Watchmen Platform.

<a id="chat-files" />

## Ask About a File or Picture

Add files with the paperclip button, drag them onto the chat when **Drop files to add them to the chat** appears, or paste a screenshot into the message box. This works in the side panel, floating window and AI chats page, including the assistant on the PDA page. Pasted text stays text.

You can add up to **5 files per message**, each up to **25 MB**. Supported files are PDF, Word, Excel, CSV, text and pictures; see the [supported formats](/en/platform-intro/pages/knowledge-base#processing). The assistant reads the files and uses them in its answer. For example, attach a work instruction and ask which checks to make before starting. You can also send only files, without a written question.

Each file appears above the message box with its name and progress: **Uploading** with a percentage, then **Reading**, then **Ready**. While a document is being read, sending waits and shows **Waiting until the file is read**. Pictures can be sent once uploaded. The assistant looks at them as pictures, such as a photo of a broken part.

If a file fails, its reason appears, such as **Can't be read** or **No text found**. It is not sent and stays above the box until you remove it with ×. Removing a file here takes it off this message. A picture without readable text shows **Picture only**: the assistant can use it in this chat, but it cannot be kept in the knowledge base.

<a id="keep-chat-files" />

### Choose Where to Keep the Files

When **Also keep these files in your knowledge base?** appears, choose:

- **Keep in knowledge base**: keep eligible files as **Private**, visible only to you there. You can [share them later](/en/platform-intro/pages/knowledge-base#visibility).
- **Only this chat**: use the files in this conversation. They do not appear in the knowledge base.

Select **Remember my choice** before choosing where to keep the files to use that choice for future chat files too. Change it later in your [profile](/en/platform-intro/pages/user-profile#ai-preferences).

Keeping is available only when you have Knowledge Base page access and an Admin has allowed the assistant's knowledge base area under **Admin Panel → A.I. → AI assistant**. Otherwise, the question, keeping actions and profile setting are hidden; you can still use files in the chat.

Sent messages show their files, including when you reopen the conversation. Select a file to open its preview; a kept file opens in the knowledge base. To keep an eligible file later, open its three-dot menu, **More for this file**, and choose **Keep in knowledge base**. The **Knowledge base** mark shows that it was kept. Follow [ask the assistant about a file](/en/platform-intro/workflows/chat-attachments).

<a id="delete-chat" />

### Delete a Chat and Its Files

Deleting a conversation opens **Delete this conversation?** in the Watchmen Platform. Files used only in that chat are deleted with it. Files kept in your knowledge base stay. Check what you need before confirming: deletion cannot be undone.

Files you attach but neither send nor keep in the knowledge base are removed after about a day.

<a id="answer-modes" />

## Choose an Answer Mode

Choose **Answer mode** at the bottom left inside the message box:

| Mode | Best for | Credits per answer |
| --- | --- | --- |
| **Auto** (recommended) | Most questions | 1–3 |
| **Fast** | Short, simple questions | 1 |
| **Deep analysis** (previously **Thorough**) | Examines data, compares and checks sources, then gives causes and recommendations; takes longer | 5 |

A web search adds 1 credit; failed answers are free. **Web search** is off until an Admin switches it on and applies only to the assistant in Watchmen, not connected apps.

<a id="opening-and-changing" />

## Review Changes and Opened Pages

Before a change, read **Review this change**: nothing changes until you press **Confirm**. Forms are only filled in for you to check and save. Under **Opening pages**, **Ask first** is the default; **Automatic** lets the assistant open pages and forms by itself from the side panel or floating chat, but does not confirm changes for you. On the AI chat page, it always asks before opening a page or form, even with **Automatic**. Choose **Open &lt;page&gt; and keep chatting in a floating window** or **Stay here** to remain on the chat page.

When you ask the assistant to open a new ticket, it can fill in the name, description, people, machines, orders, tags and due date. For example, ask it to open a ticket for Anna about order 4711 due Friday. Check the filled-in details and press **Create Ticket** yourself. See [the ticket panel](/en/platform-intro/pages/kanban#ticket-panel).

## Arrange the Chat Window

The chat is docked at the side by default. Use **Pop out** to move and resize a floating window, or **Dock to the side** to return it. Phones keep the docked chat. On the AI chat page, **Pop out** in the conversation header continues the same conversation in the floating window. Opening a page or form from that page does the same after you agree. **Continued from the AI chat page** confirms where the conversation came from.

<a id="chat-memory" />

## Continue a Long Chat

The chat-length ring beside the title appears once the chat is about half full. When it gets very long, the assistant summarizes the earlier part automatically. **Earlier part summarized** marks it; **Show summary** shows the text. In the ring’s tooltip, **Compact chat**, beside **New chat**, does the same on request.

<a id="memory" />

## Keep Personal Memory

Memory is on unless you switch it off in your profile or an Admin switches it off for the company; it lets the assistant remember facts and preferences across chats and find earlier chats. Only you see it: use **Undo** under **Saved to memory**, or [edit and delete memories in your profile](/en/platform-intro/pages/user-profile#ai-memory).

<a id="credits" />

## When Credits Run Out

When AI credits are shown, the chat shows what is left this month, what is used up, whether **Fast** still works and when credits reset. Your Admin chooses **When credits run out**: **Pause** is the default, so **Auto** and **Deep analysis** wait until next month and only **Fast** works for a few questions per person per day. With **Allow overage**, answers continue up to the **Extra credits per month** your Admin sets; extra credits are billed separately. See [AI settings and limits](/en/platform-intro/pages/admin-panel#ai-settings).

Admins also see **Need more credits? Write to** with [tech@novoai.de](mailto:tech@novoai.de) when company credits run out. For the credit breakdown, open [Usage in the Admin Panel](/en/platform-intro/pages/admin-panel#ai-credits). If you are not an Admin, ask your Admin for more credits.

<a id="connected-apps" />

## Connect an Outside AI App

An Admin first switches on **AI apps** in the **AI assistant** card. Open your profile → **Connected apps → How to connect**, choose **Claude**, **ChatGPT** or **Other apps**, copy the **Connector URL** and follow the steps shown there.

Sign in with your own Watchmen account. The approval page names the app and lists what it can read; press **Allow**. The app sees only what you may see. **Disconnect** in **Connected apps** removes access at once. With **Changes allowed**, it may also make changes your company allows, asking before each one.

<a id="tips" />

## Ask a Clear Question and Keep the Source

Include the exact label and context. For example, “What does PRO mean on the Hall Plan?” can be answered from the [glossary](/en/platform-intro/concepts/glossary). “Compare Machine A's idle time for this shift” needs the relevant company data access.

If a name matches several machines or orders, or none, the assistant asks you to choose from real names, or answers for all matches when that is short. A clear request such as “Create a ticket for Machine A” is prepared right away so you only need to press **Confirm**.

For metric questions, include machine, date range, shift mode, and quantity source. Consult [calculations](/en/platform-intro/concepts/calculations) for confirmed definitions and limits. Search stored conversation titles, rename useful conversations descriptively, and star them for later retrieval.

<a id="document-sources" />

### Open a Document Source

Select a document source in an answer to open the [Knowledge Base preview](/en/platform-intro/pages/knowledge-base#preview) at the cited page or section. The source shows **Private document** or **Company document**. Use its download icon to save the file; the original file name is kept when available.

Only you can see and search your private documents, including when you ask the assistant. Admins cannot see other people's private documents. Company documents follow your machine access; you always see your own documents. Opening a source still requires access to the document and the Knowledge Base page.

## Outcomes and Limits

### Common Outcomes
- Users resume earlier context instead of starting over.

### Limits and Empty States
- A new conversation has no history until the first message is sent.
- If AI access is switched off for your account, the chat says so; ask your Admin.
