## Overview
Let a user finish password recovery by setting a new password.

Users arrive from a reset link or a prior recovery step.

## Access
<Callout kind="info" title="Access details">
- Roles: Any User
- Visibility: Public
- Primary routes: `/auth/reset-password`
</Callout>

Users in the middle of the password recovery flow.

## What You Can See
- New-password inputs and submission controls.

## What You Can Do
- Set a replacement password and complete the reset.

## Main Entities
- User

## Outcomes and Limits
### Common Outcomes
- The user can sign in again with the new password.

### Limits and Empty States
- The reset link or reset context must still be valid.
