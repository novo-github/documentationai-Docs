## Overview

**Access:** Admins create and edit templates. Anyone with access to a machine uses its template on Data Acquisition V3, including Admins.

Open **Admin Panel → PDA access templates** (previously **BDE access templates**). A template sets shared choices for the selected machines. Everything it leaves open stays each person’s own choice. PDA and BDE refer to the same machine operator screen.

## What You Can See

The list shows each template’s name and **Machines using this template**. It shows the first three machine names, then **+N more**. Hover over the names to see the full list. **No machines** means the template is not assigned to a machine. Each row has **Edit** and **Delete**.

Open the information icon beside a title to read its explanation.

## What You Can Do

Choose **New template**, or edit or delete an existing template. In the editor, give it a unique name and select machines from the list grouped by hall. A machine already using another template shows that template’s name. Selecting it moves the machine to this template when you save. Each machine can use only one template. Click a hall name or its checkbox to select every machine in that hall. If all are already selected, clicking clears the hall’s selection.

A name is required, with up to 80 characters, and must be unique within your company. Capitalisation and spaces before or after the name do not make it different: “Saws” and “ saws ” count as the same name. Names in other companies do not count. Saving a duplicate shows **A template with this name already exists.**

The editor lists, in order: **Name**, **Machines using this template**, **Always shown**, **Always highlighted**, **Use a fixed auto-refresh**, **Use a fixed sorting**, **Allowed on the PDA page**, and **AI on the PDA page**.

Follow [Make the PDA Page the Same on Several Machines](/en/platform-intro/workflows/bde-access-templates) to create a template and check it on a PDA page.

## Display Settings

| Setting | Effect on Data Acquisition V3 |
| --- | --- |
| **Always shown** | Lists fields grouped like **Card Display Settings**. Adds fields to each person’s visible fields. These fields stay ticked and locked in **Card Display Settings**. Other fields remain optional. The order itself always stays visible. |
| **Always highlighted** | Offers eight fields: **Order Date**, **Delivery Date**, **Order Notes**, **Work Order Notes**, **Product Description**, **Operation Description**, **Operation Notes**, and **Assignment Notes**. Adds highlights when those fields are shown. It does not make a hidden field visible. People can add other highlights but cannot remove these. |
| **Use a fixed auto-refresh** | Refreshes orders and data every 1, 3, 5, or 10 minutes. Nobody can change that interval on the PDA page. |
| **Use a fixed sorting** | Replaces personal sorting on these machines. Choose queue position or at least one sorting rule. With queue-position sorting, choose **Running and on-hold orders** (**Keep in place** / **At the top**) and **Orders waiting on a previous operation** (**Keep in place** / **At the bottom**). The PDA page shows the sorting for review only. |

Locked choices show **Set by the template**. Fixed sorting shows **Sorting is set by the template**. Personal choices stay saved and apply again when the template no longer fixes that setting. Without fixed sorting, personal sorting applies, or the company sorting if the person has no saved choice.

New templates start without required fields, highlights, fixed sorting, or fixed refresh.

Turning on **Use a fixed sorting** starts from the company sorting only if a company sorting is saved in the Planner and the template had no fixed sorting before. Otherwise, the starting choices are unchanged. **Use company sorting** appears in the sorting section only when company sorting exists. It shows a tick while the template already uses that sorting. It copies the sort mode and rules; choices for running and on-hold orders and for orders waiting on a previous operation stay unchanged. Without company sorting, the section keeps its usual reset to the built-in default.

Review the sorting before saving the template. Sort rules stay locked while queue-position sorting is on; turn it off to edit the rules.

Saving is available only after you change the template.

## Allowed Actions

Under **Allowed on the PDA page**, an on switch allows the action. All actions start on for a new template. Switch off an action to block it on the selected machines’ PDA pages. Blocked action buttons and edit icons stay visible, readable, and disabled. Hover over or tap one to read **Locked for this machine (PDA template).**

| Switch | What switching it off changes |
| --- | --- |
| **Change the order status** | The status stays visible, but its menu cannot be opened. After **Stop**, **Complete** and **Keep on hold** still work when the planned quantity is reached. Reopening completed operations has its own switch. |
| **Reopen completed operations** | Disables **Set on hold** in **Recently completed**. Handed-over parts still have no reopening button. The completed cards remain readable. This is allowed by default, including in existing templates. |
| **Correct interval times and quantities** | The interval list stays readable. Edit icons stay visible but disabled; start and end times remain plain text. |
| **Edit notes and order details** | You can read the order’s side panel but cannot edit its notes or details. **Save** stays visible and disabled, even when nothing has changed. |
| **Tick off parts in the parts list** | Keeps the list visible, but prevents ticking or reopening parts on the PDA page. **Tick all** is unavailable there. Ticking in the Planner and order details stays possible. |
| **Add orders on the machine** | **Create** stays visible but disabled. Search remains available to filter work already on the machine, but shows no unplanned operations. |
| **Take orders from the hall pool** | **Assign to machine** stays visible but disabled on pool cards. |
| **Send orders back to the pool** | The action to return work or pass on its remaining quantity stays visible but disabled. |

Preparation, production start, stop, quantity booking, downtime reasons, **PDA Assist**, and warnings remain available as before.

## AI on the PDA Page

Admins choose the AI options under **AI on the PDA page**. Both switches are off by default and apply to everyone on the selected machines' PDA pages, including Admins.

| Switch | What switching it on allows |
| --- | --- |
| **Ask AI in the knowledge base tab** | Questions to the AI assistant inside **Knowledge Base**, for people with AI assistant access. |
| **Fill in tickets with AI** | Shows the microphone on the **Add Ticket** card in the PDA page’s **Tickets** tab for people with AI assistant access who may create tickets. They speak, check the filled-in ticket and create it themselves. [Follow the steps](/en/platform-intro/workflows/pda-ticket-voice). |

Machines without a template have no AI in these places. With Knowledge Base access, you can still save notes, photos and files when AI is off. These switches do not change other pages. See [knowledge on the PDA page](/en/platform-intro/pages/data-acquisition#knowledge).

## Changes and Limits

Changes reach open PDA pages at their next automatic refresh, every 5 minutes unless another interval is set. Use the page’s refresh button or reload the page to apply them immediately. Other devices do not update instantly; a screen left open keeps the old choices until one of these happens.

Removing a machine from a template, or deleting the template, returns it to personal settings. The deletion confirmation shows how many machines are affected. Editing a template keeps its inactive machines assigned even when they do not appear in the machine selection.

Templates apply only to Data Acquisition V3. They do not change the Planner, other pages, or Data Acquisition V2. Without a template, personal display choices apply; AI in the knowledge tab and when creating tickets from the PDA page is off. Page and machine access remain separate from template choices.
