## Overview

**Access:** Admin or Page Access `scheduler`, with relevant Machine Access. [Roles and access](/en/platform-intro/concepts/roles-and-access).

Let users define weekly machine shift coverage in a structured planner view.

Users open it from the Planner section in the main navigation.

## What You Can See

- A machine picker grouped by hall.
- A week selector with previous and next controls.
- A weekly grid for machine shift assignment.

## What You Can Do

- Select the machines to plan.
- Move between weeks.
- Add, clear, and save shift selections for each machine and day.

## Shifts, Shift Groups, and Active Shifts

A **Shift (Schicht)** has a start, end, and optional breaks. A **Shift group (Schichtgruppe)** is a weekly pattern of shifts by weekday assigned to machines. **Whole day** covers the full day.

**This machine uses active shifts** means that the machine follows activity instead of the weekly shift schedule. An **Active shift** starts at idle, production, or preparation. The shift group stays assigned but is not used. Switching on removes scheduled shifts from today onward and keeps shifts already recorded today. Switching off ends the running active shift immediately and creates scheduled shifts from the group from today. Administrators change this in [Machine Configuration](/en/platform-intro/workflows/machine-configuration).

For machines using scheduled shifts, **All Day** uses 24 hours while **Planned** uses scheduled shift time. A changed schedule can therefore change the time window being compared.

### Common Outcomes

- Unsaved changes remain local until saved.
