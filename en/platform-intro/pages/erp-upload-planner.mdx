## Overview

Help users import order data safely through mapping, preview, and commit steps.

Users open it through the protected ERP upload route.

## Access

<Callout kind="info" title="Access details">
- Visibility: Protected
- Primary routes: `/admin-panel/erp-uploads`
</Callout>

## What You Can See

- File upload controls.
- Column-mapping sections.
- Machine-resolution tools and dry-run previews.

## What You Can Do

- Upload a spreadsheet.
- Map columns to the platform’s order fields.
- Resolve machine references.
- Preview the result and commit the import.

## Main Entities

- Spreadsheet Row
- Production Order
- Product
- Machine

## Outcomes and Limits

### Common Outcomes
- Users import many orders at once without creating them manually.

### Limits and Empty States
- The page depends on file quality and correct column mapping.
