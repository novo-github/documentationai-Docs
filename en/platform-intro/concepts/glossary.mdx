## Find the Label You See on Screen

Each entry keeps English and German interface labels together. Search for the exact caption, such as **PRO**, **AA**, **AG**, **WDB**, or **Vorber.** PRO means Performance; AA is Work Scrap; AG is the operation-priority chip; WDB is the Knowledge Base. Definitions link to the page where you can use the concept.

Related references: [calculations](/en/platform-intro/concepts/calculations) and [roles and access](/en/platform-intro/concepts/roles-and-access).

## 0–9 / +

### +1day / +1week / +1month / +1Tag

Quick date-shift controls on order and access-key forms; the German forms use Tag, Woche, and Monat.

[Learn more](/en/platform-intro/pages/admin-panel).

### 1v1 / 1 V 1 / Versus

Older names for Versus, the side-by-side machine comparison page.

[Learn more](/en/platform-intro/pages/versus).

### 2FA / OTP

Two-factor authentication and a one-time password: the second sign-in step uses a six-digit email or authenticator code.

[Learn more](/en/platform-intro/workflows/two-factor-authentication).

## A

<a id="aa" />

### AA / Work / Arbeits-Ausschuss

Work Scrap: rejected parts caused by processing rather than the material. Kept separate from MA material scrap.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Accessibility patterns

Optional dots for Idle and diagonal lines for Off, making states distinguishable without color alone.

[Learn more](/en/platform-intro/pages/machines).

### Active Sessions

Devices signed in to your account. Individual sessions can be signed out remotely.

[Learn more](/en/platform-intro/pages/user-profile).

### Active shift / Aktive Schicht

Starts automatically when a machine becomes active and ends according to minimum, stop, and maximum duration settings. Switching removes scheduled shifts from today onward.

[Learn more](/en/platform-intro/pages/machine-configuration).

<a id="op-ag" />

### AG / OP / Arbeitsgang / Operation

An operation is one production step. The dashed OP chip (AG in German) shows operation priority; P shows order priority.

[Learn more](/en/platform-intro/pages/assignment-planner).

### AI / KI / Artificial intelligence

Artificial intelligence (Künstliche Intelligenz), used by the Beta Watchmen AI Assistant.

[Learn more](/en/platform-intro/pages/chat-history).

### AI Assistant / Watchmen AI / AI Chats

Beta chat assistant. Documentation only uses platform docs; Context-aware may query data areas enabled by an admin.

[Learn more](/en/platform-intro/pages/chat-history).

### Alert Rules

Classic machine alerts using conditions, recipients, and email, SMS, or webhook channels; operators cannot access the page.

[Learn more](/en/platform-intro/pages/alert-rules).

### All Day / Planned

Analytics scope: a full 24-hour day versus scheduled shift time. Compare the same mode.

[Learn more](/en/platform-intro/pages/machine-history).

### API-Access Keys

Keys used by other systems to access the platform; a newly created key is shown only once.

[Learn more](/en/platform-intro/pages/admin-panel).

### Assignment / Zuweisung

One operation placed on a machine or in a hall pool; intervals record the actual work on it.

[Learn more](/en/platform-intro/pages/assignment-planner).

### Assignment view modes

All Open has no date filter; Time Window + Open selects open work within ±1/3/5/7 days; Time Window + All Statuses includes completed and cancelled work.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Auto-Arrange

Automatically rearranges overlapping future assignments while leaving in-progress work unchanged.

[Learn more](/en/platform-intro/pages/assignment-gantt).

### Auto. / Automatically detected

Sensor-detected values, as in Cycles (Auto. / Planned). It does not mean operator-entered quantity.

[Learn more](/en/platform-intro/pages/order-detail).

### Automator

Admin-only rule engine with scope, conditions, timing, response, and an event inbox.

[Learn more](/en/platform-intro/pages/automator).

<a id="ava" />

### AVA

The sensor device attached to a machine. Its full name is not expanded in the interface. A machine without an assigned AVA has no live sensor state or KPIs.

[Learn more](/en/platform-intro/pages/machine-configuration).

### AVA assignment

Connection of an AVA device to a machine. Several devices can be assigned; dragging changes their priority.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Avg. / Ø / Average

Average value. Distinguish the three cycle-time averages and their different denominators.

[Learn more](/en/platform-intro/concepts/calculations#cycle-times).

### Avg. Cycle Duration

Total interval duration divided by detected cycles, including pauses and loading.

[Learn more](/en/platform-intro/concepts/calculations#cycle-times).

### Avg. Cycle Time (Operator Input)

Production time divided by the quantity entered by the operator.

[Learn more](/en/platform-intro/concepts/calculations#cycle-times).

### Avg. Production Cycle Time

Active production time divided by detected cycles.

[Learn more](/en/platform-intro/concepts/calculations#cycle-times).

<a id="avl" />

### AVL / Availability / Verfügbarkeit

Share of total recorded machine time in Production. AVL remains AVL in German and appears on gauges, Hall Plan figures, and kiosk bars.

[Learn more](/en/platform-intro/concepts/calculations#oee).

## B

<a id="pda-bde" />

### BDE / PDA / Betriebsdatenerfassung / Production Data Acquisition

English PDA and German BDE refer to the same operator terminal for starting work and booking quantities. PDA Entry is BDE-Eintrag; PDA Assistant is BDE-Assistent.

[Learn more](/en/platform-intro/pages/data-acquisition).

## C

### Card Display Settings / Columns / Highlight

Per-user choices of card fields and highlights. They change the display, not the underlying work.

[Learn more](/en/platform-intro/pages/assignment-planner).

### CHG / GEÄ / Changed

ERP check badge: an existing record would be updated by the import.

[Learn more](/en/platform-intro/pages/erp-upload-planner).

### Clear duration

How long an Automator condition must stay normal before an event can clear.

[Learn more](/en/platform-intro/pages/automator).

### Concurrent order prompt

Confirmation shown when starting an assignment while another is already running.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Condition group

Automator conditions combined with AND or OR; groups may be nested.

[Learn more](/en/platform-intro/pages/automator).

### Cooldown

Wait after an Automator event is resolved before its rule can trigger again.

[Learn more](/en/platform-intro/pages/automator).

### CO₂ / Carbon dioxide

Carbon dioxide estimate in Organization Statistics, based on optional Sustainability Check inputs.

[Learn more](/en/platform-intro/pages/org-stats).

### CSV / XLS / XLSX

Spreadsheet formats accepted by ERP Uploads. CSV and XLSX are also offered for downloads.

[Learn more](/en/platform-intro/pages/erp-upload-planner).

### Cumulative

Quantity-entry mode using the machine's entire counter reading, not this interval's increment.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Customer / Kunde

The recipient of the order, identified by a name or customer code.

[Learn more](/en/platform-intro/pages/order-detail).

### Cycle

One sensor-detected machine cycle, such as a stroke, part, or batch. Cycles Per Product defines how many make a finished part.

[Learn more](/en/platform-intro/pages/order-detail).

### Cycles found outside the intervals

Detected cycles belonging to no recorded work interval; useful for explaining count differences.

[Learn more](/en/platform-intro/pages/order-detail).

### Cycles Per Product / Press per Product / Zyklen / Presshübe pro Produkt

Number of machine cycles needed for one finished part.

[Learn more](/en/platform-intro/pages/orders-products).

## D

### d / ±1d / T / Days

Days in time windows and Due in labels. ±1d means a one-day window in each direction.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Dev. / Deviation / Abweichung

Actual time minus planned time. A negative time deviation means faster than planned.

[Learn more](/en/platform-intro/concepts/calculations#deviations).

### Dictate

Voice input for AI chats and Knowledge Base notes.

[Learn more](/en/platform-intro/pages/chat-history).

### Displays

Registered hall monitors with last-seen time and network information.

[Learn more](/en/platform-intro/pages/hall-plan).

### doc / Dok. / Document count

Document count in the Knowledge Base, such as 1 doc or 1 Dok.

[Learn more](/en/platform-intro/pages/knowledge-base).

### Double-tap to edit

On touch terminals, double-tap interval timestamps to edit them.

[Learn more](/en/platform-intro/workflows/data-acquisition).

### Downtime / Stillstand

Time in Idle or Off. Label it with a reason to explain the interruption.

[Learn more](/en/platform-intro/pages/timeline-analysis).

### Downtime Analysis (labeled)

Downtime grouped by its assigned reasons, not just by state.

[Learn more](/en/platform-intro/pages/timeline-analysis).

### Downtime Reduced

Reduced idle time above a machine-specific best-days baseline; it is not all idle time.

[Learn more](/en/platform-intro/concepts/calculations#organization-impact).

### Dur / Duration / Dauer

The duration of a planned or recorded period; check whether the field is planned or actual.

[Learn more](/en/platform-intro/pages/assignment-planner).

## E

### Energy monitor

Optional device measuring electrical energy, voltage, power factor, and frequency.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Energy wastage

Frontend label for energy consumed while not producing. Its exact state coverage is unconfirmed; the FAQ idle calculation is illustrative.

[Learn more](/en/platform-intro/concepts/calculations#energy).

### ERP / Enterprise Resource Planning

The company's business system from which order spreadsheets are exported for ERP Uploads.

[Learn more](/en/platform-intro/pages/erp-upload-planner).

### Est. / Estimated

An estimate, as in Est. Hourly Revenue and Est. Hourly Cost; not a measured amount.

[Learn more](/en/platform-intro/pages/org-stats).

### Event

One Automator trigger. States: New, Acknowledged, Resolved; a resolved event can be Reopened.

[Learn more](/en/platform-intro/pages/automator).

### Event Inbox / SLA Breaches

List of Automator events and count of open events past their response due time.

[Learn more](/en/platform-intro/pages/automator).

## F

### Feedback

Bugs, improvements, and feature requests sent to Novo AI. Sent, In review, Resolved, Closed are conversation states.

[Learn more](/en/platform-intro/pages/feedback).

### Focus Mode

Hides surrounding interface to enlarge the analysis.

[Learn more](/en/platform-intro/pages/timeline-analysis).

## G

### GDPR / DSGVO

General Data Protection Regulation, called Datenschutz-Grundverordnung in German; a label on sign-in pages.

[Learn more](/en/platform-intro/pages/user-profile).

### Global rule

An Automator rule with no selected machines, applying to all active machines.

[Learn more](/en/platform-intro/pages/automator).

### Good qty. / Gutmenge

Parts produced without defects, separate from material and work scrap.

[Learn more](/en/platform-intro/pages/data-acquisition).

## H

### Hall / Halle

Production area grouping machines for Hall Plan, planning columns, and Hall Pools.

[Learn more](/en/platform-intro/pages/hall-plan).

### Hall Plan / Hallenplan / Kiosk

Hall overview that can run unattended with an API key instead of a login; operators cannot access Hall Plan.

[Learn more](/en/platform-intro/pages/hall-plan).

<a id="hall-pool" />

### Hall Pool

Shared hall queue. An assignment has no specific machine until a machine in that hall claims it from PDA.

[Learn more](/en/platform-intro/pages/assignment-planner).

### Hr / Std / Hours

Hours in duration displays. Std Run Time is a different label meaning Standard run time.

[Learn more](/en/platform-intro/concepts/calculations).

## I

### Immediate order

An order created at the machine through Find/Create Immediate Order when no planned order is available.

[Learn more](/en/platform-intro/pages/data-acquisition).

### IMPACT / Impacted

ERP check badge: a calculated planning value would be affected by a change.

[Learn more](/en/platform-intro/pages/erp-upload-planner).

### incl. / inkl. / Including

Including, for example Assignment Planner access including Assignment Gantt.

[Learn more](/en/platform-intro/concepts/roles-and-access).

### Industrial minutes / Industrieminuten

One industrial minute is one hundredth of an hour, or 0.6 ordinary minutes. 500 equals 300 ordinary minutes.

[Learn more](/en/platform-intro/concepts/calculations#quantities).

### Input Quantity / Cycle Count / PDA Entry / BDE-Eintrag

Operator-entered quantity versus sensor-detected cycles. Switching the progress source changes the display only.

[Learn more](/en/platform-intro/pages/orders-products).

### Interval / Intervall

One recorded work session with start and end timestamps. Deleting it cannot be undone.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Interval Performance

Production time divided by total interval duration; differs from the overall PRO metric.

[Learn more](/en/platform-intro/concepts/calculations#cycle-times).

## J

### Job Context

Notes from order, work order, operation, and assignment, shown together at the machine.

[Learn more](/en/platform-intro/pages/data-acquisition).

## K

### Kanban / Tickets

Issue board with Open, In Progress, Resolved, Closed, and Archived tickets. Internal and External/Support types can link to machines or be moved into the Knowledge Base.

[Learn more](/en/platform-intro/pages/kanban).

<a id="kb-wdb" />

### KB / WDB / Knowledge Base / Wissensdatenbank

The company's documents, images, and notes connected to machines, orders, and products. WDB is the German short tab label.

[Learn more](/en/platform-intro/pages/knowledge-base).

### Kind / Machine / Maschine

Kind distinguishes a sensor-connected Machine from a sensorless Work center.

[Learn more](/en/platform-intro/pages/machines).

### Knowledge Base upload states

Queued, Reading, Splitting, Indexing, Linking, Review, Ready, Failed track processing; upload alone does not mean ready.

[Learn more](/en/platform-intro/pages/knowledge-base).

### Knowledge Graph / Suggested links

Visual relationships between documents and production items. Automatically suggested links must be confirmed or rejected.

[Learn more](/en/platform-intro/pages/knowledge-base).

### KPI / Key Performance Indicator / Kennzahl

A production indicator such as OEE, availability, or cycle time.

[Learn more](/en/platform-intro/concepts/calculations).

### kWh / Kilowatt-hour

Kilowatt-hour: energy consumed over time. W and kW are units of power.

[Learn more](/en/platform-intro/concepts/calculations#energy).

## L

### Last Heartbeat

Most recent time the machine device reported; separate from the machine's production state.

[Learn more](/en/platform-intro/pages/machine-details).

### Leaderboard

Admin-only machine and operator rankings. Current sidebar availability needs confirmation.

[Learn more](/en/platform-intro/pages/leaderboard).

### Legacy / V1

Older Orders V1 and single-machine ERP Upload versions, kept reachable but superseded.

[Learn more](/en/platform-intro/pages/erp-upload-planner).

### License Key

The company's licence identifier, distinct from an API access key.

[Learn more](/en/platform-intro/pages/admin-panel).

### Live Data

Mode streaming current machine readings.

[Learn more](/en/platform-intro/pages/machine-details).

### Live order

An order with an interval running right now.

[Learn more](/en/platform-intro/pages/orders-products).

### Live Utilization

Share of machines producing at this moment; not an average across the reporting period.

[Learn more](/en/platform-intro/pages/org-stats).

### Local IP / Lokale IP / MAC

Network details used to identify a registered hall display; distinct from its production figures.

[Learn more](/en/platform-intro/pages/hall-plan).

### Lookback Cycles / Gap Threshold

For Slow Consecutive Cycles, number of recent cycles checked and multiple of expected cycle time considered slow.

[Learn more](/en/platform-intro/pages/automator).

### Lts. / Litres

Litres, used for coolant output in Sustainability Check inputs.

[Learn more](/en/platform-intro/pages/org-stats).

## M

<a id="ma" />

### MA / Mat. / Material-Ausschuss

Material Scrap: parts rejected because of the material, separate from Work Scrap (AA).

[Learn more](/en/platform-intro/pages/data-acquisition).

### Machine features

Custom sensor readings with name, unit, thresholds, precision, and multiplication factor, such as temperature.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Machine rating

Configured machine targets compared with actual dashboard values, not measurements.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Machine tags / Order tags

Company labels for grouping and filtering machines or orders.

[Learn more](/en/platform-intro/pages/assignment-planner).

### Max. / Maximum

The highest value in cycle statistics.

[Learn more](/en/platform-intro/pages/order-detail).

<a id="mid-booking" />

### Mid Booking / Zwischenbuchung

Books quantities while work continues by closing and restarting the interval. If restart fails, bookings remain saved; press Start.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Min / Minutes

Minutes in duration displays. Do not confuse ordinary minutes with Industrial minutes.

[Learn more](/en/platform-intro/concepts/calculations#quantities).

### min prep / Min. Rüst

Minutes of preparation or setup for an operation.

[Learn more](/en/platform-intro/concepts/calculations#deviations).

### Min. / Minimum

The lowest value in cycle statistics. Min. Zykluszeit means minimum cycle time; Min. in a duration can mean minutes.

[Learn more](/en/platform-intro/pages/order-detail).

### min/pc / Min./Stk

Minutes per piece, used for planned operation timing.

[Learn more](/en/platform-intro/concepts/calculations#deviations).

### Minimum shift length / Stop that ends a shift / Maximum shift length

Settings controlling when an active shift ends or rolls into a new shift, at most 24 hours.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Minimum true duration

Time an Automator condition must remain true before an event is created.

[Learn more](/en/platform-intro/pages/automator).

### MTTR / Mean Time To Resolution

Automator average time from an event triggering to its resolution.

[Learn more](/en/platform-intro/pages/automator).

## N

### N/A / k. A. / Not available

A value is unavailable; it is not the same as zero.

[Learn more](/en/platform-intro/pages/machine-details).

### Needs Attention / Handlungsbedarf

Duration Exceeded, Cycle Time Degraded, Planned End Passed, or Delivery Date Passed. Completed and cancelled orders are excluded.

[Learn more](/en/platform-intro/pages/orders-products).

### NEW / NEU / New

ERP check badge: a new record would be created.

[Learn more](/en/platform-intro/pages/erp-upload-planner).

### No. / Nr. / Row number

Row number in Admin Panel tables. Nr. on an operation can instead be its sequence number.

[Learn more](/en/platform-intro/pages/admin-panel).

## O

<a id="oee" />

### OEE / Overall Equipment Effectiveness / Gesamtanlageneffektivität

Headline score combining Availability, Performance, and Quality. The exact server formula remains unconfirmed; Watchmen's time definitions differ from textbook OEE.

[Learn more](/en/platform-intro/concepts/calculations#oee).

### Order / Auftrag / External Order ID

Overall job, identified by its order name; contains work orders, operations, and assignments.

[Learn more](/en/platform-intro/pages/order-detail).

### Order Planned dates / Operation Planned dates

Order dates are shared across the order; operation dates belong to one step and can be used to sequence steps.

[Learn more](/en/platform-intro/pages/assignment-planner).

### Order priority / Operation priority

Independent urgency values for the whole order and one production step.

[Learn more](/en/platform-intro/pages/assignment-planner).

### Org Stats / Organization Statistics / Organisationsstatistiken

Admin dashboard for company-wide production, energy, and impact indicators. Live Utilization is a snapshot; Downtime Reduced, Revenue Recovered, and Still reachable describe different recovery and potential figures.

[Learn more](/en/platform-intro/pages/org-stats).

### Over Production / Quantity exceeded

Booked quantity exceeds plan. Choose Put on hold or Mark as finished after reviewing the quantities.

[Learn more](/en/platform-intro/pages/data-acquisition).

## P

### P / Order priority

Priority chip for the overall order, independent of the operation's OP or AG priority.

[Learn more](/en/platform-intro/pages/assignment-planner).

### PCS / pcs / Stk. / Pieces / Stück

Produced-piece counts. PCS on Hall Plan and kiosk figures stays unchanged across languages; pcs can appear as Stk. elsewhere.

[Learn more](/en/platform-intro/pages/hall-plan).

### PDA Assistant / BDE-Assistent

Per-machine terminal warnings, off by default and configured only by admins; Info, Warning, and Critical have different signals.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Peak Optimizer

Admin-only comparison of operators over a period to find top performers and bottlenecks.

[Learn more](/en/platform-intro/pages/peak-optimizer).

### Pinned items

Pages, machines, and hall plans pinned to the top of personal navigation.

[Learn more](/en/platform-intro/pages/machines).

### Planned Start / End / Actual Start / End

Planned dates describe the schedule; actual dates describe recorded work. Grouped order dates span the order; assignment rows have their own windows.

[Learn more](/en/platform-intro/pages/orders-products).

### Polling interval

How often an Automator rule is checked.

[Learn more](/en/platform-intro/pages/automator).

### Prep / Prep. / Vorber. / Rüst / Preparation / Vorbereitung / Rüsten

Setup before production. Vorber. is used on German PDA buttons; Rüst appears on planner cards. Both describe preparation.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Prep / Start / Stop / Continue

Preparation, production start, interval end, and resume controls. Explicit actions also include Start/End Preparation and Start/End Shift.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Priority

Urgency number, higher meaning more urgent. Company levels can be customized; the order form and custom settings expose different ranges.

[Learn more](/en/platform-intro/pages/admin-panel).

<a id="pro" />

### PRO / Performance / Leistung

Share of switched-on time used for production or preparation. PRO does not mean Production or produced pieces.

[Learn more](/en/platform-intro/concepts/calculations#oee).

### Prod / Prod. / Production / Produktion

Production, distinct from the PRO abbreviation for Performance.

[Learn more](/en/platform-intro/pages/machines).

### Product / Produkt / External Product ID

What is manufactured; External Product ID is the product name.

[Learn more](/en/platform-intro/pages/orders-products).

### Products more / less produced than detected

Difference between operator-entered production quantities and sensor-detected cycles.

[Learn more](/en/platform-intro/pages/order-detail).

### P\{code\} / P0–P9 / P1–P9

Priority-code labels in ERP presets, for example P1. Read them in the company's configured priority scheme.

[Learn more](/en/platform-intro/pages/admin-panel).

<a id="pulse" />

### Pulse

Raw machine-sensor signal over time, displayed below the timeline with resolutions of 1 minute, 30 seconds, 5 seconds, or 1 second.

[Learn more](/en/platform-intro/pages/machine-details).

## Q

### Qty / Quantity / Menge

The number of units. Distinguish planned, entered, counted, good, and scrap quantities.

[Learn more](/en/platform-intro/pages/data-acquisition).

<a id="quality" />

### Quality / Qualität

The dashboard tooltip states 95% and directs changes to an admin. Automatic replacement from quantities and the setting location are unconfirmed.

[Learn more](/en/platform-intro/concepts/calculations#oee).

### Queue Position / Queue load

Manual card sequence versus planned queue utilization. Running and on-hold cards stay at the top with Queue Position enabled.

[Learn more](/en/platform-intro/pages/assignment-planner).

## R

### Ratio thresholds

For Automator preparation duration, production deficit, cycle duration, and order completion deficit, 130% means 30% over plan or behind pace.

[Learn more](/en/platform-intro/pages/automator).

### Report archive

Generated weekly, monthly, and export reports; Queued, Building, Ready, Failed are build states.

[Learn more](/en/platform-intro/pages/trend-analysis).

### Requires active shift

Automator checks pause while the machine is outside its active shift.

[Learn more](/en/platform-intro/pages/automator).

### Revenue Recovered / Still reachable

Already recovered value versus remaining modeled potential; the latter includes half the remaining idle time.

[Learn more](/en/platform-intro/concepts/calculations#organization-impact).

### Rework Qty

Quantity needing rework; do not assume it is added to the card total without a confirmed rule.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Roadmap

Public Novo AI plan: Ideas, Planned, In progress, Released. Users can upvote items.

[Learn more](/en/platform-intro/pages/roadmap).

## S

### Scrap / Ausschuss

Rejected parts split into material scrap MA and work scrap AA.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Sec / Sek / Seconds

Seconds, the display unit for cycle times.

[Learn more](/en/platform-intro/concepts/calculations#cycle-times).

### Sensor powered by machine

Use when the sensor loses power with the machine; a missing signal then appears as Off instead of Unknown.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Seq / Nr. / Sequence / Sequenz

An operation's step number within a work order, for example 10, 20, 30.

[Learn more](/en/platform-intro/pages/order-detail).

### Shift / Schicht / Whole day

Named work period with start, end, and optional breaks; Whole day covers the entire day.

[Learn more](/en/platform-intro/pages/scheduler).

### Shift group / Schichtgruppe

Weekly pattern assigning shifts to weekdays, attached to machines.

[Learn more](/en/platform-intro/pages/scheduler).

### Shift Planner / Scheduler / Schichtplaner

Page for assigning shifts and operators to machines by day or week.

[Learn more](/en/platform-intro/pages/scheduler).

### Silence / Unsilence

Temporarily mute or restore one alert type or all alerts for a machine.

[Learn more](/en/platform-intro/pages/alert-rules).

### SLA / Service Level Agreement

In Automator, the number of minutes responders have before an open event is overdue.

[Learn more](/en/platform-intro/pages/automator).

### Snooze

Temporarily hide a PDA warning, default 15 minutes. It returns if the condition persists.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Start Preparation / End Preparation / Start Shift / End Shift

Explicit actions for preparation and shift boundaries; Prep starts a preparation interval, while Start starts production.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Status / Unplanned / Planned / Released / In Progress / Hold / Completed / Cancelled

Order and assignment states: Ungeplant, Geplant, Freigegeben, In Bearbeitung, In Wartestellung, Abgeschlossen, Storniert. Order status follows assignments; Released timing is unconfirmed.

[Learn more](/en/platform-intro/pages/orders-products).

### Std Run Time / Standard run time

Planned production time per unit.

[Learn more](/en/platform-intro/concepts/calculations#deviations).

### Sum / Summ. / Totals

Totals row in order analysis; Avg. or Ø is the averages row.

[Learn more](/en/platform-intro/pages/order-detail).

### Sustainability Check

Optional company inputs for the CO₂ estimate, including waste, renewable share, coolant, transport, and material efficiency.

[Learn more](/en/platform-intro/pages/org-stats).

## T

### Templates / Auto-resolve / Notify on resolve / Escalation

Automator presets and responses: close on a cleared condition, notify on closure, or notify another group when overdue.

[Learn more](/en/platform-intro/pages/automator).

### Timeline / Production / Idle / Off / Stopped / Preparation / Unknown

State bar: Production green (Produktion), Idle orange (Leerlauf), Off/Stopped red (Aus/Gestoppt), Preparation blue (In Vorbereitung), Unknown grey (Unbekannt).

[Learn more](/en/platform-intro/pages/machines).

### Timeline Analysis / Trend Analysis

Reports examining machine states within a period versus KPI trends across days.

[Learn more](/en/platform-intro/pages/timeline-analysis).

### Timeline ranges / Time range / Idletime Distribution

Duration buckets, such as 1–5 or 5–30 minutes, used to count downtime frequency and duration.

[Learn more](/en/platform-intro/pages/timeline-analysis).

### Timeline reason / Downtime reason / Stillstandsgrund

Admin-defined label explaining a timeline period, with name, description, color, type, and level 1–5. The type/level effects are unconfirmed.

[Learn more](/en/platform-intro/pages/timeline-analysis).

### Timeline rules

Automatic reasons selected by specific reason rule, then its DEFAULT rule, then Global rules, for Off, Idle, or Preparation.

[Learn more](/en/platform-intro/pages/machine-configuration).

### Total / Planned / Input / Counted

Assignment quantities: planned target, entered quantity, detected count, and total input plus MA plus AA.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Trust this device for next 30 days

Skip the second authentication step on the trusted device for 30 days.

[Learn more](/en/platform-intro/workflows/two-factor-authentication).

## U

### Unassigned operation

An operation without a machine, listed in the Assignment Planner's left panel.

[Learn more](/en/platform-intro/pages/assignment-planner).

### Unbound / unlabeled machine time

Machine time between recorded intervals belonging to no order.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Unlabeled timeline warning

Marker for downtime without an assigned reason.

[Learn more](/en/platform-intro/pages/data-acquisition).

### util. / Util. / Ausl. / Utilization / Auslastung

Planned load of a machine queue, based on planned durations, not recorded production.

[Learn more](/en/platform-intro/pages/assignment-planner).

## W

### Waiting on a previous step / Blocked by

An earlier operation is unfinished. Start anyway is available; review the dependency before using it.

[Learn more](/en/platform-intro/pages/data-acquisition).

### Webhook

Alert delivery to another system by URL, optionally with Basic, Bearer, or custom-header authentication and a payload template.

[Learn more](/en/platform-intro/pages/alert-rules).

### Wi-Fi / WLAN

Wireless network information for a registered hall display.

[Learn more](/en/platform-intro/pages/hall-plan).

### WO / Work Order / Arbeitsauftrag

The part of an order for one product, with a planned quantity and operations.

[Learn more](/en/platform-intro/pages/order-detail).

### Work center / Arbeitsplatz

Workplace without AVA. Can receive assignments but has no sensor KPIs, status-counter inclusion, or sensor-based alert/Automator triggers.

[Learn more](/en/platform-intro/pages/machines).
