<a id="privacy" />

## Can my Admin see my private documents?

No. **Private** is pre-selected when you add a file or note. Only you can see and search it, including when you ask the AI assistant. Admins cannot see it either. [Learn more](/en/platform-intro/pages/knowledge-base#visibility).

<a id="share" />

## How do I share a document with my colleagues?

Open your private document and choose **Share with whole company → Share**. You can also choose **Whole company** before uploading. A Machine operator can share without approval. When a Machine operator shares a document or adds a file or note for the whole company, company Admins receive an email. Sharing as an Admin or User sends no email. Colleagues still need the relevant page and machine access. [Learn more](/en/platform-intro/workflows/knowledge-base).

<a id="unshare" />

## Can I make a shared document private again?

Yes. The person who added it or an Admin who can see it can choose **Make private** and confirm. Only the person who added it can then see and search it. If an Admin makes someone else’s document private, it disappears for that Admin too. [Learn more](/en/platform-intro/pages/knowledge-base#visibility).

<a id="filters" />

## Why is a document missing from my list?

Check **All / Private / Whole company**: **Private** shows only your own private documents. You cannot see other people’s private documents. With limited machine access, company documents linked only to other machines are hidden; those without a confirmed machine link remain visible. Files used only in a chat appear here only after you [keep them in the knowledge base](/en/platform-intro/pages/knowledge-base#chat-files). You always see your own kept documents. [Learn more](/en/platform-intro/pages/knowledge-base#visibility).

<a id="edit" />

## What do the sparkle and pencil mean, and can I correct the text?

The sparkle means **AI-generated**; the pencil means **Edited** by a person. In **About this document**, the person who added the document or an Admin who can see it can choose **Edit**, change the title, type, summary or note, then **Save**. These edits stay when the document is read again. [Learn more](/en/platform-intro/pages/knowledge-base#about-document).

<a id="links" />

## Do I have to confirm every suggested link separately?

No. Check the suggestions first, then choose **Confirm all** if they are all correct. Otherwise, confirm correct links and reject incorrect ones separately. Confirmed machine links affect who can see a company document. [Learn more](/en/platform-intro/workflows/knowledge-base).

<a id="preview" />

## How do I read the page cited by the AI assistant?

Select the document source in the answer. It opens the Knowledge Base preview at the cited page or section. You need access to the page and the document. You can also select a document in the list and use the eye button with **Open**. [Learn more](/en/platform-intro/pages/knowledge-base#preview).

<a id="preview-limit" />

## Why does the preview show only part of my file?

Long text previews show only the beginning. Download the file to read all of it. You can also download if the preview is unavailable. PDFs show the document pages, pictures are displayed, and Word, Excel and text files show their text. [Learn more](/en/platform-intro/pages/knowledge-base#preview).

<a id="retry" />

## My document failed. How do I try again?

Read the reason shown. The person who added the document or an Admin who can see it can choose **Try again** when offered. If no readable text was found, upload a clearer copy; pictures and scans are supported when readable. For an unsupported file type, use one of the supported formats. [Learn more](/en/platform-intro/pages/knowledge-base#processing).

<a id="delete" />

## Who can delete a document?

Only the person who added it or an Admin who can see it. Admins cannot delete other people’s private documents because they cannot see them. Deletion cannot be undone. To stop sharing while keeping the document for its owner, use **Make private** instead. [Learn more](/en/platform-intro/pages/knowledge-base#processing).

<a id="keep-chat-file" />

## Can I keep a file in the knowledge base after sending it in a chat?

Yes, when keeping is available for the file. Open the three-dot menu on the file in your sent message, **More for this file → Keep in knowledge base**. It appears in the knowledge base as **Private** and stays if you delete the chat. Files used only in a chat are absent from the knowledge base list, search and graph. [Follow the steps](/en/platform-intro/workflows/chat-attachments).
