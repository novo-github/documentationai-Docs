## Where can I find a report I requested earlier?

Only Administrators and Super Admins can open **Report archive**. Other users do not see it. Open **Reports** in the side menu. At the top of Timeline Analysis or Trend Analysis, select the archive button with the tooltip **Report archive** next to the **Timeline** / **Trend** switch. Filter by period, machine, and source. Select **By user** for requested reports or **Scheduled** for scheduled reports. Broaden the filters if nothing appears. Follow [Download and Update Reports](/en/platform-intro/workflows/reports).

<a id="waiting" />

## Why is my report not ready to download?

**Queued** means it is waiting to be created; **Building** means creation is underway. If creation takes longer than usual, return to the archive later if you have archive access. Otherwise, try the export again later. Download the available file once it is **Ready**. See [Report Archive](/en/platform-intro/pages/report-archive).

<a id="rebuild" />

## How do I include corrected production entries in an old report?

Select **Rebuild with current data**. The archive tells you whether the report changed and shows its version and update time. If the check finds no changes, it says so. Follow [Download and Update Reports](/en/platform-intro/workflows/reports).

<a id="failed-refresh" />

## Have I lost my report if the update fails?

No. The previous version remains available after a failed refresh. Check its version before using it and try the refresh again. See [Report Archive](/en/platform-intro/pages/report-archive).

<a id="email" />

## Does “Not emailed” mean my report failed?

No. **Not emailed** describes delivery, while **Ready** means the report is available. Scheduled weekly and monthly reports can be emailed; the archive shows how many emails were sent. See [Report Archive](/en/platform-intro/pages/report-archive).

<a id="missed-delivery" />

## Can I still receive a scheduled report I missed?

After a delivery problem, the Watchmen team can manually resend the latest scheduled weekly report for the last completed week, the latest scheduled monthly report for the last completed month, or both. Only recipients missed by the failed delivery receive it; anyone who already received the report gets no second email. Redelivery is not automatic, and customers cannot start it themselves.

Ask an administrator to download the ready report from **Report archive**, or contact the Watchmen team if the email did not arrive. See [Report Archive](/en/platform-intro/pages/report-archive).
