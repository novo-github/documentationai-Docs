<a id="privacy" />

## Kann mein Admin meine privaten Dokumente sehen?

Nein. Auf der Seite Wissensdatenbank ist beim Hinzufügen einer Datei oder Notiz **Privat** vorausgewählt. Einträge von der BDE-Seite gelten dagegen für **Ganzes Unternehmen**. Nur Sie können Ihr privates Dokument sehen und durchsuchen, auch wenn Sie den KI-Assistenten fragen. Auch Admins sehen es nicht. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#visibility).

<a id="share" />

## Wie teile ich ein Dokument mit meinen Kollegen?

Öffnen Sie Ihr privates Dokument und wählen Sie **Mit dem ganzen Unternehmen teilen → Teilen**. Sie können auch vor dem Hochladen **Ganzes Unternehmen** wählen. Ein Maschinenbediener kann ohne Freigabe teilen. Teilt ein Maschinenbediener ein Dokument oder fügt auf der Seite Wissensdatenbank eine Datei oder Notiz für das ganze Unternehmen hinzu, erhalten die Admins des Unternehmens eine E-Mail. Das Speichern eines Eintrags auf der BDE-Seite sendet keine E-Mail an Admins. Beim Teilen durch einen Admin oder User wird keine E-Mail verschickt. Kollegen benötigen weiterhin die entsprechenden Seiten- und Maschinenrechte. [Mehr erfahren](/de/platform-intro/workflows/knowledge-base).

<a id="unshare" />

## Kann ich ein geteiltes Dokument wieder privat machen?

Ja. Die Person, die es hinzugefügt hat, oder ein Admin mit Zugriff kann **Privat machen** wählen und bestätigen. Danach kann nur noch die Person, die es hinzugefügt hat, das Dokument sehen und durchsuchen. Macht ein Admin das Dokument einer anderen Person privat, verschwindet es auch für diesen Admin. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#visibility).

<a id="filters" />

## Warum fehlt ein Dokument in meiner Liste?

Prüfen Sie **Alle / Privat / Ganzes Unternehmen**: **Privat** zeigt nur Ihre eigenen privaten Dokumente. Private Dokumente anderer Personen sehen Sie nicht. Bei eingeschränktem Maschinenzugriff bleiben Firmendokumente verborgen, die nur mit anderen Maschinen verknüpft sind. Dokumente ohne bestätigte Maschinenverknüpfung bleiben sichtbar. Nur im Chat verwendete Dateien erscheinen hier erst, wenn Sie sie [in der Wissensdatenbank behalten](/de/platform-intro/pages/knowledge-base#chat-files). Ihre eigenen behaltenen Dokumente sehen Sie immer. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#visibility).

<a id="edit" />

## Was bedeuten Funkel-Symbol und Stift, und kann ich den Text korrigieren?

Das Funkel-Symbol bedeutet **KI-erstellt**, der Stift **Bearbeitet** durch eine Person. Unter **Über dieses Dokument** kann die Person, die es hinzugefügt hat, oder ein Admin mit Zugriff **Bearbeiten** wählen, Titel, Dokumentart, Zusammenfassung oder Notiz ändern und **Speichern** wählen. Diese Änderungen bleiben beim erneuten Lesen erhalten. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#about-document).

<a id="links" />

## Muss ich jede vorgeschlagene Verknüpfung einzeln bestätigen?

Nein. Prüfen Sie zuerst die Vorschläge und wählen Sie **Alle bestätigen**, wenn alle stimmen. Andernfalls bestätigen Sie passende Verknüpfungen und lehnen falsche einzeln ab. Bestätigte Maschinenverknüpfungen beeinflussen, wer ein Firmendokument sehen darf. [Mehr erfahren](/de/platform-intro/workflows/knowledge-base).

<a id="preview" />

## Wie lese ich die vom KI-Assistenten zitierte Seite?

Wählen Sie die Dokumentquelle in der Antwort. Die Vorschau in der Wissensdatenbank öffnet sich auf der zitierten Seite oder beim zitierten Abschnitt. Sie benötigen Zugriff auf die Seite und das Dokument. Sie können auch ein Dokument in der Liste wählen und über das Augensymbol mit **Öffnen** ansehen. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#preview).

<a id="preview-limit" />

## Warum zeigt die Vorschau nur einen Teil meiner Datei?

Lange Textvorschauen zeigen nur den Anfang. Laden Sie die Datei herunter, um alles zu lesen. Das geht auch, wenn die Vorschau nicht verfügbar ist. PDFs zeigen die Dokumentseiten, Bilder werden angezeigt. Bei Word-, Excel- und Textdateien sehen Sie den Text. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#preview).

<a id="retry" />

## Mein Dokument ist fehlgeschlagen. Wie versuche ich es erneut?

Lesen Sie den angezeigten Grund. Die Person, die das Dokument hinzugefügt hat, oder ein Admin mit Zugriff kann **Erneut versuchen** wählen, wenn die Aktion angeboten wird. Wurde kein lesbarer Text gefunden, laden Sie eine besser lesbare Fassung hoch. Lesbare Bilder und Scans werden unterstützt. Bei einem nicht unterstützten Dateityp verwenden Sie eines der unterstützten Formate. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#processing).

<a id="delete" />

## Wer kann ein Dokument löschen?

Nur die Person, die es hinzugefügt hat, oder ein Admin mit Zugriff. Admins können private Dokumente anderer Personen nicht löschen, da sie diese nicht sehen. Das Löschen lässt sich nicht rückgängig machen. Möchten Sie nicht mehr teilen, das Dokument aber für die Person behalten, die es hinzugefügt hat, wählen Sie **Privat machen**. [Mehr erfahren](/de/platform-intro/pages/knowledge-base#processing).

<a id="keep-chat-file" />

## Kann ich eine bereits im Chat gesendete Datei in der Wissensdatenbank behalten?

Ja, wenn das Behalten für diese Datei möglich ist. Öffnen Sie an der Datei in Ihrer gesendeten Nachricht das Drei-Punkte-Menü **Mehr zu dieser Datei → In Wissensdatenbank behalten**. Die Datei erscheint als **Privat** in der Wissensdatenbank und bleibt erhalten, wenn Sie den Chat löschen. Nur im Chat verwendete Dateien fehlen in Liste, Suche und Graph der Wissensdatenbank. [Schritt für Schritt](/de/platform-intro/workflows/chat-attachments).

<a id="pda-save" />

## Wie hinterlasse ich einen Tipp oder ein Foto für die nächste Schicht?

Öffnen Sie die BDE-Seite → **Wissensdatenbank → Zur Wissensdatenbank hinzufügen**. Wählen Sie den passenden Auftrag, schreiben oder diktieren Sie Ihren Tipp oder nutzen Sie **Foto aufnehmen oder hinzufügen** oder **Datei hinzufügen**. Prüfen Sie die Verknüpfungen zu Maschine, Auftrag und Produkt und wählen Sie **Speichern**. Der Text wird als Notiz gespeichert, jedes Foto und jede Datei als eigener Eintrag. [Schritt für Schritt](/de/platform-intro/workflows/pda-knowledge).

<a id="pda-visibility" />

## Wer sieht meine Einträge an der Maschine, und bekommt mein Admin eine E-Mail?

Einträge von der BDE-Seite gelten für **Ganzes Unternehmen**. Alle in Ihrem Unternehmen, die die Maschine sehen dürfen, finden sie im Tab, auf der Seite Wissensdatenbank und über den KI-Assistenten. Admins sehen sie auf der Seite Wissensdatenbank, erhalten für diese Einträge aber keine E-Mail. [Mehr erfahren](/de/platform-intro/pages/data-acquisition#knowledge).

<a id="pda-ai" />

## Warum kann ich auf der BDE-Seite Wissen speichern, aber die KI nicht fragen?

**KI fragen** benötigt Ihren Zugriff auf den KI-Assistenten und die Vorlageneinstellung **KI fragen im Tab Wissensdatenbank** für diese Maschine. Ein Admin legt dies unter **Admin-Panel → BDE-Zugriffsvorlagen → KI auf der BDE-Seite** fest. Die Option ist zunächst aus; Maschinen ohne Vorlage bieten hier keine KI. Mit Zugriff auf die Wissensdatenbank bleibt das Speichern verfügbar. Andere Seiten sind nicht betroffen. [Vorlage einrichten](/de/platform-intro/workflows/bde-access-templates).

<a id="pda-edit" />

## Kann ich eine an der Maschine gespeicherte Notiz korrigieren?

Ja. Öffnen Sie den Eintrag im Tab Wissensdatenbank der BDE-Seite, wählen Sie **Bearbeiten** und nach Ihren Änderungen **Speichern**. Das darf nur die Person, die ihn hinzugefügt hat, oder ein Admin. Bei Notizen aus diesem Tab können Sie **Text** sowie Titel, Dokumentart, Zusammenfassung und Notiz ändern. Bei älteren Notizen und hochgeladenen Dateien lassen sich hier nur die Angaben ändern. [Mehr erfahren](/de/platform-intro/pages/data-acquisition#knowledge).

<a id="pda-conversation" />

## Kann ich weiterfragen, ohne die BDE-Seite zu verlassen?

Ja, wenn **KI fragen** erlaubt ist. Folgefragen und angebotene Antwortmöglichkeiten setzen dieselbe Unterhaltung im Tab fort. Nutzen Sie **Weitermachen**, wenn angeboten, prüfen Sie vorbereitete Änderungen vor dem Bestätigen oder beginnen Sie mit **Neue Frage** von vorn. Quellen öffnen sich im Tab. **Im Chat öffnen** öffnet die Unterhaltung in einem neuen Browser-Tab. [Schritt für Schritt](/de/platform-intro/workflows/pda-knowledge).
