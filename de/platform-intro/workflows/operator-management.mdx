## Ziel

Halten Sie die Mitarbeitendenliste korrekt, damit Planung und Produktionsverfolgung die richtigen Personen widerspiegeln.

## Bevor Sie beginnen

<Callout kind="info" title="Ablaufzugriff">
- Einstiegspunkte: `/admin-panel`
</Callout>

Beginnen Sie auf dem [Administrationsbereich](/de/platform-intro/pages/admin-panel).

### Voraussetzungen
- Der Benutzer hat Administratorzugriff.

## Schritte

<Steps>
  <Step title="Öffnen Sie den Bereich zur Mitarbeitendenverwaltung" icon="arrow-right" title-type="p">
    Öffnen Sie den Bereich zur Mitarbeitendenverwaltung.
  </Step>
  <Step title="Fügen Sie eine neue Person hinzu oder bearbeiten Sie eine vorhandene" icon="arrow-right" title-type="p">
    Fügen Sie eine neue Person hinzu oder bearbeiten Sie eine vorhandene.
  </Step>
  <Step title="Speichern Sie die Personendaten" icon="arrow-right" title-type="p">
    Speichern Sie die Personendaten.
  </Step>
  <Step title="Verwenden Sie die aktualisierte Mitarbeitendenliste in Planungs- oder maschinenbezogenen Seiten" icon="arrow-right" title-type="p">
    Verwenden Sie die aktualisierte Mitarbeitendenliste in Planungs- oder maschinenbezogenen Seiten.
  </Step>
</Steps>

## Entscheidungspunkte

- Ob der Benutzer eine neue Person anlegen oder eine vorhandene aktualisieren soll.

## Erwartetes Ergebnis

Mitarbeitende stehen für Planungs- und produktionsbezogene Abläufe zur Verfügung.

## Häufige Probleme und Sonderfälle

- Alte oder doppelte Datensätze erschweren eine verlässliche Planung.
- Eine neue Person kann in der Plattform vorhanden sein, bevor sie irgendwo zugewiesen wurde.
