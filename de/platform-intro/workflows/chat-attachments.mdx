## Ziel

Erhalten Sie eine Antwort zu Ihrem Dokument oder Bild und entscheiden Sie, wo die Datei bleiben soll.

## Bevor Sie beginnen

<Callout kind="info" title="Ablaufzugriff">
Admins haben Zugriff auf den Assistenten. User und Maschinenbediener benötigen Zugriff auf **KI-Chats** und eingeschalteten **KI-Zugang**. Zum Behalten von Dateien benötigen Sie zusätzlich Zugriff auf die Wissensdatenbank. Ein Admin muss diesen Bereich unter **Admin-Panel → K.I. → KI-Assistent** freigeben. Sie können Chatdateien auch ohne diese Möglichkeit zum Behalten nutzen.
</Callout>

### Voraussetzungen

- Halten Sie bis zu 5 Dateien mit jeweils bis zu 25 MB bereit: PDF, Word, Excel, CSV, Text oder Bilder. Siehe [unterstützte Formate](/de/platform-intro/pages/knowledge-base#processing).
- Überlegen Sie, was Sie wissen möchten, etwa welche Prüfungen eine Arbeitsanweisung vorsieht.

## Schritte

<Steps>
  <Step title="Öffnen Sie den Assistenten und fügen Sie Dateien hinzu" icon="arrow-right" title-type="p">
    Öffnen Sie den seitlichen Assistenten, sein frei bewegliches Fenster oder die Seite **KI-Chats**. Das geht auch mit dem Assistenten auf der BDE-Seite. Nutzen Sie die Büroklammer, ziehen Sie Dateien auf den Chat oder fügen Sie ein Bildschirmfoto ins Nachrichtenfeld ein. Jede Datei erscheint mit Name und Fortschritt über dem Feld.
  </Step>
  <Step title="Wählen Sie, wo die Dateien bleiben" icon="arrow-right" title-type="p">
    Erscheint **Diese Dateien auch in deiner Wissensdatenbank behalten?**, aktivieren Sie zuerst **Auswahl merken**, wenn Ihre Wahl auch für künftige Dateien gelten soll. Wählen Sie dann **In Wissensdatenbank behalten** oder **Nur dieser Chat**. Behaltene Dateien sind **Privat**. Haben Sie bereits eine Voreinstellung im Benutzerprofil gewählt, gilt diese ohne Rückfrage. Ist das Behalten nicht möglich, bleiben die Dateien im Chat.
  </Step>
  <Step title="Prüfen Sie die Dateien und senden Sie Ihre Frage" icon="arrow-right" title-type="p">
    Warten Sie bei Dokumenten, bis nach **Wird gelesen** der Status **Bereit** erscheint. Bilder können Sie nach dem Hochladen senden. Lesen Sie mögliche Fehlerhinweise und entfernen Sie die fehlgeschlagene Datei mit ×. Schreiben Sie Ihre Frage und senden Sie mit der Papierflieger-Schaltfläche unten rechts. Sie können Dateien auch ohne Text senden.
  </Step>
  <Step title="Lesen Sie die Antwort und öffnen Sie eine Datei" icon="arrow-right" title-type="p">
    Der Assistent nutzt Ihre Dateien für seine Antwort. Wählen Sie eine Datei an Ihrer gesendeten Nachricht, um die Vorschau zu öffnen. Eine behaltene Datei öffnet sich in der Wissensdatenbank. Um eine geeignete Chatdatei später zu behalten, öffnen Sie ihr Drei-Punkte-Menü **Mehr zu dieser Datei → In Wissensdatenbank behalten**. Die Kennzeichnung **Wissensdatenbank** bestätigt, dass die Datei behalten wurde.
  </Step>
</Steps>

## Entscheidungspunkte

- Möchten Sie eine andere Voreinstellung? Öffnen Sie im Benutzerprofil **Mein KI-Assistent → Im Chat hinzugefügte Dateien**. Wählen Sie **Jedes Mal fragen**, **In meiner Wissensdatenbank behalten** oder **Nur im Chat**.
- Sollen Kollegen eine behaltene Datei nutzen? Folgen Sie [Dokument prüfen und teilen](/de/platform-intro/workflows/knowledge-base).
- Möchten Sie die Unterhaltung löschen? Behalten Sie vorher geeignete Dateien, die Sie noch benötigen. Nur in diesem Chat verwendete Dateien werden mit ihm gelöscht; behaltene Dateien bleiben. Das Löschen lässt sich nicht rückgängig machen.

## Erwartetes Ergebnis

Ihre Nachricht zeigt die Dateien und der Assistent nutzt sie für seine Antwort. Zum Behalten ausgewählte Dateien erscheinen außerdem als private Dokumente in Ihrer Wissensdatenbank.

## Häufige Probleme und Sonderfälle

- **Warten, bis die Datei gelesen ist**: Warten Sie vor dem Senden, bis das Dokument fertig gelesen wurde.
- **Nicht lesbar** oder **Kein Text gefunden**: Prüfen Sie den Grund neben der Datei. Fehlgeschlagene Dateien werden nicht gesendet und bleiben über dem Feld, bis Sie sie mit × entfernen.
- **Nur als Bild**: Der Assistent kann das Bild im Chat ansehen. Es lässt sich aber nicht in der Wissensdatenbank behalten, da kein lesbarer Text gefunden wurde.
- Keine Auswahl zum Behalten und keine Profileinstellung: Prüfen Sie mit Ihrem Admin Ihren Zugriff auf die Wissensdatenbank und ob dieser Bereich für den Assistenten freigegeben ist. Sie können Dateien weiterhin im Chat nutzen.
- Angehängt, aber weder gesendet noch in der Wissensdatenbank behalten: Solche Dateien werden nach etwa einem Tag entfernt. Senden Sie die Nachricht, wenn Sie ihre Dateien weiter im Chat nutzen möchten.
