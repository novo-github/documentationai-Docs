## Ziel

Legen Sie verständliche Gründe fest und wählen Sie, welche Maschinen sie anbieten.

## Bevor Sie beginnen

<Callout kind="info" title="Ablaufzugriff">
Erforderlicher Zugriff: Administrator. Speichern Sie eine neue Maschine vor der Grundauswahl.
</Callout>

### Voraussetzungen

Prüfen Sie vorhandene Gründe vor dem Anlegen. Stimmen Sie Namen und Codes mit Ihrem Team ab.

## Schritte

<Steps>
  <Step title="Öffnen Sie die Gründe einer Maschine" icon="arrow-right" title-type="p">
    Öffnen Sie als Administrator **Maschineneinstellungen → Stillstandsgründe**. Sie können Gründe auch in der Verwaltung der Zeitachsengründe im [Administrationsbereich](/de/platform-intro/pages/admin-panel) anlegen und bearbeiten.
  </Step>
  <Step title="Wählen Sie alle Gründe oder eine feste Liste" icon="arrow-right" title-type="p">
    Mit **Alle Gründe (Standard)** erscheinen später angelegte Gründe automatisch. Wählen Sie alternativ **Nur ausgewählte Gründe** und mindestens einen Grund. Nutzen Sie Suche und Filter. **Alle sichtbaren auswählen** ergänzt sichtbare Gründe. Leeren entfernt die gesamte Auswahl.
  </Step>
  <Step title="Erstellen oder bearbeiten Sie einen Grund" icon="arrow-right" title-type="p">
    Nutzen Sie **Neuer Grund** oder die Bearbeitungsaktion neben einem Grund. Geben Sie Name und Beschreibung ein. Der optionale **Code** muss im Unternehmen eindeutig sein und wird in Großbuchstaben gespeichert. Wählen oder ergänzen Sie eine **Kategorie**. Nutzen Sie **Farbe wählen**, einen eingegebenen Farbwert oder **Zufällige Farbe**.
  </Step>
  <Step title="Wählen Sie die Verfügbarkeit" icon="arrow-right" title-type="p">
    Wählen Sie unter **Verfügbar auf Maschinen**, wo der Grund angeboten werden soll. Beim Anlegen aus den Maschineneinstellungen ist diese Maschine vorausgewählt. Wählen Sie eine mit **Alle Gründe** markierte Maschine ab, erhält sie eine feste Liste der übrigen aktuellen Gründe. Später angelegte Gründe erscheinen dort nicht mehr automatisch.
  </Step>
  <Step title="Speichern und prüfen Sie die Maschinenauswahl" icon="arrow-right" title-type="p">
    Speichern Sie den Grund und prüfen Sie die Auswahl der Maschine. Speichern Sie den Tab, falls noch ungespeicherte Änderungen bestehen. Wurde der Grund angelegt, aber seine Maschinenauswahl nicht gespeichert, bearbeiten Sie ihn weiter. Prüfen und speichern Sie die Liste erneut. Legen Sie kein Duplikat an.
  </Step>
  <Step title="Übertragen Sie die Auswahl auf andere Maschinen" icon="arrow-right" title-type="p">
    Nutzen Sie **Auf andere Maschinen übertragen**, wählen Sie Ziele und prüfen Sie den Ersetzungshinweis. Die Bestätigung ersetzt deren Listen durch die aktuelle Auswahl oder den Modus für alle Gründe. Prüfen Sie das Ergebnis.
  </Step>
</Steps>

## Automatische Regeln

Maschinenauswahlen begrenzen manuelle Zuordnungen. Automatische Zeitachsenregeln verwenden weiterhin alle Unternehmensgründe. Richten Sie diese in der [Maschinenkonfiguration](/de/platform-intro/pages/machine-configuration) ein.

## Entscheidungspunkte

Wählen Sie alle Gründe für automatischen Zugriff auf spätere Ergänzungen oder eine feste Liste für eine kürzere Bedienerauswahl. Verwenden Sie einen gemeinsamen Grund bei gleicher Bedeutung wieder. Änderungen gelten für alle Maschinen.

## Erwartetes Ergebnis

Bediener sehen die Gründe, die auf ihrer Maschine erlaubt sind. Diagramme zeigen Codes und ihre Erklärungen vorhandene Kategorien.

## Häufige Probleme und Sonderfälle

- Ein doppelter Code lässt sich nicht speichern. Wählen Sie einen anderen Code oder bearbeiten Sie den vorhandenen Grund.
- Über die Verfügbarkeitsliste können Sie einer Maschine nicht ihren letzten verfügbaren Grund entziehen. Geben Sie der genannten Maschine zuerst einen anderen Grund oder lassen Sie diesen ausgewählt.
- Beim Löschen eines Grundes bleiben frühere Stillstandseinträge erhalten, verlieren aber ihren Grund. Eine Maschine ohne verbleibenden ausgewählten Grund bietet danach alle Gründe. Lesen Sie vor der Bestätigung den Löschhinweis.
- Ändert jemand gleichzeitig die Auswahl, wird der aktuelle Stand geladen. Prüfen Sie ihn und versuchen Sie es erneut.
- Ein geöffnetes Terminal übernimmt neue Verfügbarkeit beim nächsten Aktualisieren. Auch eine abgelehnte Grundauswahl aktualisiert die Liste.
