## Ziel

Halten Sie die Hallenstruktur der Fabrik korrekt, damit Maschinen richtig gruppiert und angezeigt werden können.

## Bevor Sie beginnen

Administratoren, die für die Anlagenstruktur verantwortlich sind.

<Callout kind="info" title="Ablaufzugriff">
- Rollen: Admin
- Einstiegspunkte: `/admin-panel`
</Callout>

Beginnen Sie auf dem [Administrationsbereich](/de/platform-intro/pages/admin-panel).

### Voraussetzungen
- Der Benutzer hat den richtigen Administratorzugriff.

## Schritte

<Steps>
  <Step title="Öffnen Sie den Bereich zur Hallenverwaltung" icon="arrow-right" title-type="p">
    Öffnen Sie den Bereich zur Hallenverwaltung.
  </Step>
  <Step title="Erstellen Sie eine Halle oder öffnen Sie eine vorhandene" icon="arrow-right" title-type="p">
    Erstellen Sie eine Halle oder öffnen Sie eine vorhandene.
  </Step>
  <Step title="Legen Sie den Hallennamen und die geforderten Hallendetails fest" icon="arrow-right" title-type="p">
    Legen Sie den Hallennamen und die vom System geforderten Hallendetails fest.
  </Step>
  <Step title="Speichern Sie die Halle" icon="arrow-right" title-type="p">
    Speichern Sie die Halle.
  </Step>
  <Step title="Prüfen Sie die Maschinenzuordnung erneut" icon="arrow-right" title-type="p">
    Prüfen Sie die Maschinenzuordnung erneut, wenn sich die Hallenstruktur geändert hat.
  </Step>
</Steps>

## Entscheidungspunkte

- Ob eine Halle erstellt, umbenannt oder außer Betrieb genommen werden soll.

## Erwartetes Ergebnis

Maschinen können in Planungs- und Überwachungsansichten der richtigen Halle zugeordnet werden.

## Häufige Probleme und Sonderfälle

- Änderungen an der Hallenstruktur können Nacharbeiten an Maschinendatensätzen erforderlich machen.
- Leere Hallen können existieren, bevor ihnen Maschinen zugewiesen werden.
