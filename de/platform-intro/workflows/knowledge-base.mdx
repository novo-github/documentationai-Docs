---

## Ziel

Fügen Sie der Watchmen-Plattform nützliches Wissen hinzu, prüfen Sie es und legen Sie fest, wer es sehen darf.

## Bevor Sie beginnen

<Callout kind="info" title="Ablaufzugriff">
Admins, User und Maschinenbediener benötigen Zugriff auf die **Wissensdatenbank**. Nur die Person, die ein privates Dokument hinzugefügt hat, kann es teilen. Die Person, die ein Dokument hinzugefügt hat, oder ein Admin mit Zugriff kann seine Angaben bearbeiten, die Verarbeitung erneut versuchen oder es löschen.
</Callout>

### Voraussetzungen

- Halten Sie eine Datei oder schriftliche Notiz bereit. Prüfen Sie die [unterstützten Formate und Grenzen](/de/platform-intro/pages/knowledge-base#processing).
- Entscheiden Sie, ob das Dokument privat bleiben oder im Unternehmen geteilt werden soll.

## Schritte

<Steps>
  <Step title="Legen Sie die Sichtbarkeit fest" icon="arrow-right" title-type="p">
    Öffnen Sie die **Wissensdatenbank**. Lassen Sie im Bereich zum Hochladen **Privat** ausgewählt, damit nur Sie das Dokument sehen, auch wenn Sie den KI-Assistenten fragen. Wählen Sie **Ganzes Unternehmen**, wenn Sie es sofort teilen möchten. Fügen Sie als Maschinenbediener so eine Datei oder Notiz hinzu, erhalten die Admins des Unternehmens eine E-Mail. Admins sehen keine privaten Dokumente anderer Personen.
  </Step>
  <Step title="Fügen Sie Ihr Dokument hinzu" icon="arrow-right" title-type="p">
    Hängen Sie Ihre Datei an und laden Sie sie hoch oder schreiben und speichern Sie eine Notiz. Warten Sie, bis das Dokument gelesen wurde. Wählen Sie es in der Liste, um den Status zu prüfen. Schlägt die Verarbeitung fehl, beachten Sie den angezeigten Grund und wählen Sie **Erneut versuchen**, wenn die Aktion angeboten wird.
  </Step>
  <Step title="Prüfen Sie die Dokumentangaben" icon="arrow-right" title-type="p">
    Vergleichen Sie unter **Über dieses Dokument** die Angaben **Titel**, **Dokumentart**, **Zusammenfassung** und **Beantwortet Fragen wie** mit dem Dokument. Das Funkel-Symbol kennzeichnet Angaben als **KI-erstellt**. Wählen Sie den Stift mit **Bearbeiten**, korrigieren Sie Titel, Dokumentart, Zusammenfassung oder die optionale Notiz und wählen Sie **Speichern**. Geänderte Angaben zeigen **Bearbeitet** und bleiben beim erneuten Lesen erhalten.
  </Step>
  <Step title="Prüfen Sie vorgeschlagene Verknüpfungen" icon="arrow-right" title-type="p">
    Prüfen Sie die vorgeschlagenen Maschinen, Aufträge und Produkte. Bestätigen Sie passende Verknüpfungen und lehnen Sie falsche ab. Wählen Sie **Alle bestätigen**, wenn alle Vorschläge stimmen. Bestätigte Maschinenverknüpfungen beeinflussen, wer ein Firmendokument sehen darf.
  </Step>
  <Step title="Teilen Sie das geprüfte Dokument bei Bedarf" icon="arrow-right" title-type="p">
    Wählen Sie für Ihr privates Dokument **Mit dem ganzen Unternehmen teilen**, lesen Sie die Bestätigung und wählen Sie **Teilen**. Teilt ein Maschinenbediener ein Dokument oder fügt eine Datei oder Notiz für das ganze Unternehmen hinzu, erhalten die Admins des Unternehmens eine E-Mail. Beim Teilen durch einen Admin oder User wird keine E-Mail verschickt. Eine Freigabe ist nicht erforderlich. Überspringen Sie diesen Schritt, wenn das Dokument privat bleiben soll.
  </Step>
  <Step title="Lesen Sie die Quelle und finden Sie sie wieder" icon="arrow-right" title-type="p">
    Öffnen Sie die Vorschau über das Augensymbol mit **Öffnen**. Speichern Sie die Adresse als Lesezeichen oder senden Sie sie an Kollegen mit Zugriff. Wählen Sie eine Dokumentquelle in einer KI-Antwort, öffnet sich die Vorschau auf der zitierten Seite oder beim zitierten Abschnitt. Laden Sie die Datei herunter, wenn die Vorschau nur den Anfang zeigt oder nicht verfügbar ist.
  </Step>
</Steps>

## Entscheidungspunkte

- Möchten Sie nur Ihre privaten Dokumente sehen? Wählen Sie **Privat** über der Liste. **Ganzes Unternehmen** zeigt geteilte Dokumente, die Sie sehen dürfen; **Alle** umfasst beides.
- Möchten Sie nicht mehr teilen? Die Person, die das Dokument hinzugefügt hat, oder ein Admin mit Zugriff kann **Privat machen** wählen und bestätigen. Danach sieht nur noch die Person, die es hinzugefügt hat, das Dokument. Macht ein Admin das Dokument einer anderen Person privat, verliert auch der Admin den Zugriff.

## Erwartetes Ergebnis

Ihr Dokument ist für die berechtigten Personen verfügbar. Die geprüften Angaben und Verknüpfungen helfen Ihnen, den Inhalt einzuordnen. In der Vorschau können Sie die Quelle lesen.

## Häufige Probleme und Sonderfälle

- Kein lesbarer Text gefunden: Laden Sie eine besser lesbare Fassung hoch, etwa ein schärferes Foto oder die Originaldatei. Dieselbe unlesbare Fassung erneut zu versuchen hilft nicht.
- Ein Kollege kann es nicht öffnen: Prüfen Sie, ob es privat ist, ob der Kollege Zugriff auf die Wissensdatenbank hat und ob bestätigte Maschinenverknüpfungen seinen Zugriff einschränken. Das Weitergeben der Adresse erteilt keinen Zugriff. Ihre eigenen Dokumente sehen Sie immer.
- Ein Firmendokument, das nur mit für Sie gesperrten Maschinen verknüpft ist, bleibt verborgen, sofern Sie es nicht selbst hinzugefügt haben. Dokumente ohne bestätigte Maschinenverknüpfung bleiben im Rahmen Ihres Maschinenzugriffs sichtbar.
- Prüfen Sie vor dem Löschen, ob Sie das Dokument noch benötigen. Das Löschen lässt sich nicht rückgängig machen. **Privat machen** erhält das Dokument für die Person, die es hinzugefügt hat.
