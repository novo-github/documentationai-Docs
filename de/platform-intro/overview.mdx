## Überblick

Der Plattform-Einstieg bündelt die Seitenreferenz der Plattform und die aufgabenbasierten Ablaufanleitungen an einem Ort, damit Sie ohne Kontextverlust von der Orientierung zur Umsetzung wechseln können.

<Callout kind="tip" title="Wählen Sie die Ansicht, die zu Ihrem Ziel passt">
  Verwenden Sie **Seiten**, wenn Sie verstehen möchten, wofür ein Bildschirm gedacht ist. Verwenden Sie **Abläufe**, wenn Sie eine geführte Abfolge zum Erledigen einer Aufgabe brauchen.
</Callout>
