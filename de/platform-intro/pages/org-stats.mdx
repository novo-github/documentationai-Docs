## Überblick

Geben Sie eine unternehmensweite Sicht auf die operative Leistung statt auf eine einzelne Maschine.

Benutzer öffnen diese Seite über die Hauptnavigation, wenn ihre Rolle es zulässt.

## Zugriff

<Callout kind="info" title="Zugriffsdetails">
- Sichtbarkeit: Geschützt
- Primäre Routen: `/org-stats`
</Callout>

## Was Sie sehen können

- Zusammenfassende Kennzahlen und Visualisierungen auf Unternehmensebene.
- Vergleichsindikatoren über die gesamte Organisation hinweg statt nur für eine Maschine.

## Was Sie tun können

- Prüfen Sie die Leistung auf einer breiteren Ebene.
- Nutzen Sie die Seite als Ausgangspunkt, bevor Sie zu spezifischeren Maschinen- oder Berichtseiten wechseln.

## Hauptentitäten

- Unternehmen
- Maschine
- Leistungskennzahl

## Ergebnisse und Grenzen

### Typische Ergebnisse
- Benutzer erkennen, ob ein Problem nur eine Maschine betrifft oder organisationsweit sichtbar ist.

### Grenzen und Leerzustände
- Diese Seite ist für die breite Analyse hilfreicher als für Schritt-für-Schritt-Aufgaben.
