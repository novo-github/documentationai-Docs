## Überblick

Geben Sie Benutzern einen Ort, an dem sie ihre Kontoinformationen prüfen und angemeldete Geräte verwalten können.

Benutzer öffnen diese Seite über profilbezogene Navigation.

## Zugriff

<Callout kind="info" title="Zugriffsdetails">
- Sichtbarkeit: Geschützt
- Primäre Routen: `/user`
</Callout>

## Was Sie sehen können

- Persönliche Kontoinformationen, einschließlich Ihrer Telefonnummer und deren Verifizierung.
- Aktive Sitzungen mit Gerät, Browser, Betriebssystem, IP-Adresse, Standort und Anmeldezeit.

## Was Sie tun können

- Die eigenen profilbezogenen Details prüfen.
- Eine Telefonnummer hinzufügen, verifizieren, ändern oder entfernen.
- Ein einzelnes Gerät abmelden.
- Alle anderen aktiven Sitzungen abmelden.

## Telefonnummer verifizieren

Bei der Verifizierung bestätigen Sie die Telefonnummer in Ihrem Konto mit einem Code, den Sie per SMS erhalten.

<Steps>
  <Step title="Fordern Sie einen Code an" icon="arrow-right" title-type="p">
    Öffnen Sie Ihr **Profil**, geben Sie Ihre Telefonnummer ein und fordern Sie einen Bestätigungscode an.
  </Step>
  <Step title="Bestätigen Sie die Nummer" icon="arrow-right" title-type="p">
    Geben Sie den sechsstelligen Code aus der SMS ein und bestätigen Sie ihn, um die Nummer zu verifizieren.
  </Step>
</Steps>

Falls die SMS nicht ankommt, warten Sie die kurze Wartezeit ab, bevor Sie einen neuen Code anfordern.

Um die Nummer zu entfernen oder zu ändern, nutzen Sie auf derselben Seite die Funktion zum Entfernen der Telefonnummer. Wenn Sie eine andere Nummer verwenden möchten, fügen Sie diese hinzu und wiederholen Sie die Verifizierung.

## Aktive Sitzungen prüfen und beenden

Eine Sitzung entspricht einer Anmeldung bei Ihrem Konto auf einem Gerät oder in einem Browser. Prüfen Sie Gerät, Browser, Betriebssystem, IP-Adresse, Standort und Anmeldezeit, um Ihre aktiven Anmeldungen zuzuordnen.

Nutzen Sie die Abmeldefunktion einer einzelnen Sitzung, wenn Sie diese nicht mehr benötigen oder nicht zuordnen können. Um alle Sitzungen außer der aktuell verwendeten zu beenden, wählen Sie die Option zum Abmelden aller anderen aktiven Sitzungen. So können Sie auf Ihrem aktuellen Gerät weiterarbeiten, während die anderen Anmeldungen beendet werden.

## Hauptentitäten

- Benutzer
- Sitzung
- Gerät

## Ergebnisse und Grenzen

### Typische Ergebnisse
- Benutzer bestätigen ihre Kontoinformationen und prüfen, wo ihr Konto angemeldet ist.
- Benutzer beenden eine einzelne Sitzung oder alle Sitzungen außer der aktuellen.

### Grenzen und Leerzustände
- Standort- und Gerätedetails hängen von den für die jeweilige Anmeldung verfügbaren Informationen ab.
